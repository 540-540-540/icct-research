# 原 D 与关系条件化 D：配对训练协议

本轮只比较 `original_D` 与 `relation_D`，均使用种子 2026，从头训练固定 40 轮。GNN 仅作历史参照。权威运行目录为服务器 `/home/dell/YrM/ICCT`。

## 本轮要回答的问题

原 D 通过 45 米邻域筛选车辆，再用车辆自身编码得到的量子 Q/K 状态匹配。新 D 在匹配过程中加入当前时刻两车的相对位置和运动关系，检验这种关系信息能否改善轨迹预测。该改动是待验证的设计，尚无本轮完整训练效果结论。

两组都重新训练 40 轮，避免把原 D 20 轮与新 D 40 轮的差异误归因于结构。历史 D20 权重不接续到本轮；恢复只允许使用本轮自身、配置与来源完全一致的检查点。

## 唯一结构变化

原 D 保持现有 `FactorialGraph(qubits=2, radius=45)`。新 D 继承相同的编码器、Q/K/V 参数和读出，只增加一个无偏置、零初始化的 `Linear(7,4)`，共 28 个参数。完整模型可训练参数分别为 610276 和 610304。

接收车辆为 i，发送车辆为 j，直接复用强 GNN 的边特征函数：

- 相对位置 `(p_j-p_i)/30`：2 维。
- 相对速度 `(v_j-v_i)/15`：2 维。
- 距离 `distance/45`：1 维。
- 接近速度 `closing/15`：1 维。
- 截断到 20 秒的碰撞时间 `TTC/20`：1 维。

其中方向使用 `Δp / max(distance, 1)`，`closing = -Δv·direction`。正接近速度时 `TTC = min(distance/max(closing,0.25),20)`，否则为 20 秒；尺度、符号和截断与现有 GNN 完全一致。

关系角度为 `phi_ij = pi * tanh(W_e * e_ij)`。每个注意力比特依次执行 RY、RZ，得到两比特关系旋转 R。匹配为：

`gamma_ij = <K_j | R(e_ij) | Q_i>`。

在完整线路中对应 `K_j† R_ij Q_i`。只有双方有效、距离不超过 45 米且非自环的边启用关系旋转；自环始终 R=I。V_j、邻居索引、后选择概率和读出保持原定义：3 个索引比特、2 个注意力比特、2 个 value 比特，共 7 比特；15 个混合态 Pauli 读出、16 个相干读出及成功概率，合计 32 维，再映射到 128 维。

新增参数初值为零，使新 D 在训练开始时退化为原 D。两组共有图参数和时间模型逐张量相同。时间模块继续使用既有 GPT-2、LoRA 和轨迹头。本轮不增加蒸馏、时间交互模块或量子比特。

## 数据与训练规则

| 项目 | 固定设置 |
|---|---|
| 比较组 | original_D、relation_D |
| 种子 | 2026 |
| 训练集 | 全部 5549 个 train origins |
| 选点集 | 全部 400 个 V_select origins |
| 轮数 | 两组均固定 40 轮，patience=41 |
| 批次 | batch=16，micro-batch=1，每轮 347 批，尾批 13 |
| 优化步 | 每组预期 13880 步；结束时核验实际值 |
| SNR | 5/10/15/20 dB；每个 origin 在 40 轮内各见 10 次 |
| 顺序 | 相同种子、origin 清单与 SNR 调度 |
| 图学习率 | 0.0003 |
| 权重衰减 | theta 为 0；新增边权重为 0.01；其他参数沿用共享训练器 |
| 设备 | original_D 使用 cuda:0；relation_D 使用 cuda:1 |
| 选点指标 | V_select 的 J=ADE+0.5FDE |
| 禁用数据 | 不访问 V_confirm 或 test |

末尾不足整批的数据按实际批次大小归一化，不丢弃。两组使用同一前端输入、标准化、标签、时间模型预训练权重与共享训练器。独立进程避免互相覆盖训练器状态；文件锁防止重复启动。来源合同记录运行代码、配置、训练/选点数据和预训练模型，启动、恢复与完成均核验。

## 启动验证记录

- 图数值检查：关系权重为零时，与原 D 的输出最大误差 1.33e-15，共有参数/输入梯度最大误差 3.20e-14。
- 非零关系：生产计算与独立完整 7 比特线路的输出最大误差 2.55e-15，全部参数/输入梯度最大误差 7.82e-14。
- 掩码、置换、无效 NaN 槽、自环、45 米边界和接近零的后选择概率均通过检查。
- 完整模型初始化检查：两组共有参数相同；真实输入下，零关系权重的端到端预测一致。
- 隔离训练检查：两组各用 17 个 train origins、2 个 V_select origins，运行 1 轮，共 2 次更新；完整批次与尾批均实际执行，四档 SNR 验证分母一致。
- 新边权重的 17 次梯度观测全部有限，最大范数 0.0141163；28 个权重均发生更新，最大绝对变化 0.00060036。
- 完成后的恢复检查通过，仍为 2 次更新；这不等同于中途精确恢复测试。拒绝未指定模式和冲突模式的启动。

详细证据见同目录 `graph_checks.json`、`checks.json`、`smoke_checks.json` 和 `smoke_summary.json`。隔离检查的临时权重在验收后清理，检查摘要保留。小样本分数不用于判断结构优劣。

## 结果解释

完整训练后分别报告：两组第 40 轮的共同末轮指标；各自按 J 选择的最佳检查点及其完整 ADE/FDE/J 三元组；逐 SNR 指标；最后 5 轮趋势。若单独列 ADE 或 FDE 最低值，必须注明其所在轮及完整三元组，不能拼成一个不存在的检查点成绩。

先判断关系旋转是否改善原 D，再结合曲线判断训练是否充分。40 轮完成本身不证明收敛。本轮仅有一个配对种子，不能据此宣称多种子稳定性、相对 GNN 的公平最终优势或量子加速。

## 运行入口

在服务器项目根目录使用 `/home/dell/YrM/envs/ICCT/bin/python experiments/qgat_relation/run.py`：

- `--self-check`：初始化、优化器分组、数据调度和零边预测检查，不做参数更新。
- `--check-only`：核验当前数据、设备和来源状态，不启动训练。
- `--smoke`：隔离小样本检查，不写入正式结果目录。
- `--run`：按本协议启动两组 40 轮训练。
- `--run --resume`：仅恢复本轮相同来源和配置的正式训练。

正式权重和逐轮验证记录位于 `results/qgat_relation/seed2026/`；状态、日志和最终配对汇总位于 `reports/qgat_relation/seed2026/`。历史 factorial/formal 入口、配置和结果保持原样。
