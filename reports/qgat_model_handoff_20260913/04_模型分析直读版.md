每个场景窗口包含 20 个历史时间点，间隔 0.1 秒，每帧至多 8 个车辆槽位。图节点是车辆，不是基站，也不是不同类型的运动参数。感知前端已将输入处理为位置、速度及有效标记；训练预测模型时读取固定缓存，不反向训练感知前端。

## 3. 原 D：一次量子匹配与聚合，32 维读出

### 3.1 节点编码与 Q/K/V

原 D 的实现从 `project/experiments/qgat_factorial/graph.py:32` 开始。每个车辆节点把四个标准化连续量、`track_exists`、`detected` 拼成 6 维向量，经带偏置的 `Linear(6,6)`，再计算 `a=π·tanh(encoder(input))`，得到六个角度。每个状态量子比特使用三个角度。

两个比特上的门序相同：先分别执行 `RY → RX → RY` 数据编码，再执行一个两比特 `CNOT`，最后分别执行可训练的 `U3`。编码门序见 `project/experiments/qgat_candidate/graph.py:14`；双比特组合见 `project/experiments/qgat_factorial/graph.py:9`。

Q、K、V 三个分支使用同一个经典角度编码器；分支末端的 `U3` 参数相互独立，保存在 `theta[3,2,3]` 中，共 18 个可训练量子门角。每个分支的参数跨车辆、跨时间点共享。Q/K/V 都是长度为 4 的复振幅向量，不能把其中的 Q/K/V 理解为 GPT-2 的 768 维注意力向量。

这里没有多轮量子图更新，没有多头 QGAT，也没有把第一轮更新后的节点重新送入第二轮 Q/K/V。每帧图特征只完成一次聚合，然后交给时间模型。

### 3.2 邻域、匹配与后选择

对接收车辆 i，邻居集合包含所有存在且与 i 距离不超过 45 米的车辆，并包含有效自环。邻域根据同帧 `state_hat` 的位置计算；不是根据标准化坐标计算。实现见 `project/experiments/qgat_factorial/graph.py:81`。

设有效邻居数为 `d_i`，原 D 的匹配系数和未归一化的索引—值联合振幅为：

\[
\gamma_{ij}=\langle K_j|Q_i\rangle,\qquad
b_{ij}=\frac{\gamma_{ij}}{\sqrt{d_i}}|V_j\rangle.
\]

然后计算后选择成功概率 `p_i=Σ_j ||b_ij||²`，当 `p_i>10⁻¹²` 时，用 `b_ij/√p_i` 得到归一化联合振幅。这里的 `gamma` 是复内积，代码中没有经典 softmax。不能把复匹配幅度、模平方形成的权重和后选择成功概率混称为一个“注意力分数”。实现见 `project/experiments/qgat_factorial/graph.py:88`、`:104`。

完整线路包含 3 个索引比特、2 个注意力比特、2 个值比特，总计 7 比特。索引寄存器在该接收车辆的有效邻居上均匀制备；注意力寄存器先制备 Q，再按邻居索引控制施加 K 的逆操作，值寄存器按索引制备 V。取注意力寄存器的 `|00⟩` 分支，得到上述联合振幅。完整线路见 `project/experiments/qgat_factorial/graph.py:58`。

生产路径使用 PennyLane 的双比特局部态，结合精确张量收缩计算相同结果；不是以经典边 MLP 替代量子输出，也不是截断近似。完整 7 比特线路保留为独立核验路径。当前是 `default.qubit`、`shots=None` 的状态向量模拟，量子计算使用复数双精度并通过 backprop 求导，没有真实量子硬件或有限 shots 测量实验。

### 3.3 32 个读出是什么

读出函数见 `project/experiments/qgat_factorial/graph.py:17`。设归一化后的邻居振幅为 `a_ij`，两比特 Pauli 集为 `{I,X,Y,Z}⊗{I,X,Y,Z}`：

1. **15 个混合态观测量**：对每个非 `II` Pauli 算子，计算 `Σ_j a_ij† P a_ij`。这相当于对索引寄存器取迹后，观察值寄存器。
2. **16 个相干观测量**：先形成 `c_i=Σ_j a_ij/√d_i`，再计算全部 16 个 `c_i† P c_i`，包括 `II`。`c_i` 没有被再次归一化，因此其中的 `II` 保存了这次相干投影的强度信息。
3. **1 个后选择成功概率**：前面的 `p_i`。

顺序为 `15 mixed + 16 coherent + success`。32 维实数读出经 `Linear(32,128) → LayerNorm(128)` 输出图特征；没有额外激活层。不能把“32 个输出数字”直接等同于“32 个独立自由度”，也不能认为映射到 128 维自动恢复了读出前丢弃的信息。

对于没有有效轨迹的槽位，最终图输出为零。对于仍存在、但后选择概率近零的车辆，原始 32 维读出置零，后面的带偏置 readout 仍会执行；因此不应误称这种有效车辆的最终 128 维输出也一定全零。代码刻意沿用这一行为。

## 4. 新 D：只在匹配中加入关系旋转

新 D 完整实现见 `project/experiments/qgat_relation/graph.py:29`。它继承原 D 的角度编码器、Q/K/V 参数、45 米邻域、V 分支和 32→128 读出，仅新增一个无偏置共享映射：

\[
W_e\in\mathbb{R}^{4\times7},\qquad
\phi_{ij}=\pi\tanh(W_e e_{ij}).
\]

因此只增加 28 个参数。`W_e` 零初始化，构造新增层时还保留了随机数状态，使新旧 D 的共享图参数以及后续初始化能够保持一致。见 `project/experiments/qgat_relation/graph.py:31`。

### 4.1 七维关系直接复用强 GNN 的定义

该函数直接引用 `prediction.classical._source.build_edge_features`，见 `project/experiments/qgat_relation/graph.py:7`。真正定义位于 `project/code/00_remote_shared_dependencies/target_interaction_graph.py:31`。

对于 `i←j`，定义 `Δp=p_j−p_i`、`Δv=v_j−v_i`，边向量为：

\[
e_{ij}=\left[\frac{\Delta p_x}{30},\frac{\Delta p_y}{30},
\frac{\Delta v_x}{15},\frac{\Delta v_y}{15},
\frac{r}{45},\frac{s_c}{15},\frac{\min(\tau,20)}{20}\right].
\]

其中 `r=||Δp||`，方向向量使用 `Δp/max(r,1)`，接近速度 `s_c=−Δv·direction`。若 `s_c>0`，`τ=r/max(s_c,0.25)`；否则 `τ=20`。这是代码中的简化关系指标，不是真实碰撞是否发生的判定器。两个方向的相对位置、相对速度会变号，而距离及上述接近速度不简单变号。

这些边属性仅由同帧的物理状态估计得到；没有引入未来轨迹、标签、目标身份或额外传感器通道。

### 4.2 关系进入哪里，哪些地方保持原样

每个注意力比特依次执行 `RY(φ)`、`RZ(φ)`，因此整体关系门是：

\[
R_{ij}=[R_Z(\phi_1)R_Y(\phi_0)]\otimes
[R_Z(\phi_3)R_Y(\phi_2)],\qquad
\gamma_{ij}=\langle K_j|R_{ij}|Q_i\rangle.
\]

矩阵乘法中的右侧门先执行。完整受控线路对应的顺序是 Q → R → K†；R 没有同时放在 Q/K 两侧相互抵消。见 `project/experiments/qgat_relation/graph.py:14`、`:37`、`:88`。

关系旋转仅对存在、非自环、45 米内的有效边启用；自环强制 `R=I`，无效边不旋转。关系旋转本身是两个单比特旋转的张量积，没有新增纠缠门。各接收者—发送者对使用同一个 `W_e`，没有按车辆身份设独立参数。

新 D 仍使用原来的 `V_j`：邻居传给不同接收车辆的值态，只有匹配幅度不同，值态本身没有按 `e_ij` 重新生成。也没有新增第二轮消息传播、额外注意力头、蒸馏教师或几何损失。这些边界是分析结构效果时必须保留的事实。

## 5. 强 GNN 的实际结构与来源

本轮 GNN 的模型包装来自 `project/experiments/qgat_candidate/run_formal.py:39`，其中 `name='gnn'` 会选择 `GNNGraph()` 并接同一个 `TrajectoryPredictor(128)`。`project/prediction/classical.py:10` 中较早的 `ClassicalGNN` 类不是本轮强基线。

实际 `GNNGraph` 位于 `project/prediction/classical.py:61`，通过动态加载复用 `project/code/00_remote_shared_dependencies/target_interaction_graph.py` 中的 `DenseEdgeGraphAttention` 和边构造函数。只复用图注意力模块，不使用该历史文件后半部分 `MultiTargetForecaster` 的 GRU、时间嵌入或独立解码器。

首先，每车六维输入经过 `Linear(6,128) → SiLU → Linear(128,128)`。这里六维顺序是 `[z,detected,track_exists]`，新旧 QGAT 的顺序是 `[z,track_exists,detected]`；语义信息相同，但不能误认为两个不同编码器的权重可以直接对齐交换。

随后执行两层独立参数的图注意力，每层具有：

- 128 维节点表示，4 个头，每头 32 维；无偏置的 Q/K/V 线性映射。
- 七维物理边输入经 `7→128→4` 小网络形成每头的评分偏置。
- 评分为缩放点积加边偏置，对邻居维执行 softmax；邻域仍为 45 米、有效自环。
- 同一七维边输入经另一个 `7→128→128` 网络形成边消息，消息内容是 `V_j + edge_value(e_ij)`，再按各头注意力聚合。
- `128→128` 输出映射，以及 `128→256→128` 前馈网络；两个 LayerNorm、0.1 dropout、两个可训练标量残差门。

实际公式与门控残差见 `project/code/00_remote_shared_dependencies/target_interaction_graph.py:95`。两个标量门在初始化时为零，分别经 `tanh` 控制消息更新和前馈更新；因此该层初始为节点表示的恒等映射，之后由训练学习更新强度。不能从“初始门为零”推断最终训练中图没有工作。

第二层读取第一层更新后的节点，因此具有两轮消息传播；边特征和邻域仍来自原始同帧物理状态。GNN 的自环也经过边偏置/边消息网络，不能等同于新 QGAT 自环关系门固定为 I 的语义。

| 结构环节 | 原 D | 新 D | 强 GNN |
|---|---|---|---|
| 每帧图传播 | 一次聚合 | 一次聚合 | 两层更新 |
| 显式相对运动关系 | 只用于 45 米筛选；其余依赖节点表示间接表达 | 七维关系进入量子匹配旋转 | 七维关系同时进入评分偏置和消息内容 |
| 多头 | 无 | 无 | 每层四头 |
| 邻居值内容 | 节点自己的 V 态 | 节点自己的 V 态 | 节点 V 加接收者相关的边消息 |
| 图输出 | 32 个量子读出映射到 128 维 | 同原 D | 128 维节点表示 |
| 图内部显式残差保留节点 | 无对应的经典节点残差支路 | 同原 D | 两个门控残差更新/层 |

以上差别是真实结构差别；还不能仅靠表格认定哪一项导致误差差距。

## 6. 共用 GPT-2、LoRA 与轨迹头

`project/prediction/temporal.py:9` 的数值适配器把三路投影相加：四维标准化状态 `4→768`，两维标记 `2→768`，128 维图输出 `128→768`。后两路没有偏置。不是把三路拼成 768 维，也没有把图输出作为单独的额外 token。

因此，即使图模块的信息不充分，时间模型仍能直接看到本车标准化状态及标记。分析时应判断模型实际是否使用了图支路，不能把整模型的全部表现都归功于图模块。

GPT-2 使用本地 `models/gpt2`，严格检查为 12 层、12 个头、768 维。预训练基座权重冻结；每层融合 QKV 的 `c_attn` 添加一组 rank=8、alpha=16 的 LoRA，`A:[768,8]`、`B:[8,2304]`。不是只改 Query，也没有给输出投影、前馈层添加 LoRA。实现见 `project/prediction/temporal.py:36`、`:49`。

各车分别作为一个长度 20 的时间序列进入 GPT-2，车辆维并入 batch。GPT-2 在这里不跨车辆做注意力。跨车信息必须先经逐帧图模块，才能随本车的 token 进入时间模型。不同车辆共用同一套时序参数。位置编码由 GPT-2 添加，位置编号固定为 0…19；输出头读取最后有效历史点的表示。

只有最后历史时刻轨迹存在且 20 帧中至少存在 3 帧的车辆才预测。轨迹头为 `768→256→40`，中间使用 SiLU，将 40 个数重排为未来 20×2 个修正量；并非逐步自回归生成，也没有未来 token 交互层。

最终结果为：

\[
\hat p_i(t_0+k\Delta t)=\hat p_i(t_0)+k\Delta t\,\hat v_i(t_0)+\Delta p_{i,k},
\quad k=1,\ldots,20,\quad\Delta t=0.1s.
\]

这里的起点和速度来自末帧估计状态，不是真实末帧标签。修正量后没有额外倍率、边界截断或物理投影。实现见 `project/prediction/temporal.py:63`。训练损失使用带有效性掩码的轨迹距离，输出结构中没有额外关系监督、蒸馏损失或动力学约束项，见同文件 `:93`。

| 部分 | 原 D | 新 D | 强 GNN |
|---|---:|---:|---:|
| 图模块可训练参数 | 4,540 | 4,568 | 319,756 |
| 共用结构的时序可训练参数 | 605,736 | 605,736 | 605,736 |
| 整体可训练参数 | 610,276 | 610,304 | 925,492 |

共用时序部分由 LoRA 294,912、数值适配器 103,680、轨迹头 207,144 个参数组成。新旧 D 图参数来自 `project/reports/qgat_relation/graph_checks.json:118`；100 轮实际参数清单分别见 `project/results/qgat_extend100/seed2026/relation_D/parameters.json:1` 与 `project/results/qgat_extend100/seed2026/gnn/parameters.json:1`。冻结 GPT-2 基座不计入“可训练参数”。

图参数少不等于推理快，也不等于证明量子计算优势。本轮 QGAT 运行的是精确状态向量模拟；计算成本与物理量子设备执行成本不能互相代替。

关于对称性，应分别表述：

- 图输出对于车辆槽位的共同置换是等变的，即换序输入会相应换序输出；邻居汇总读出不依赖索引槽的编号。时间模型也按车辆共享。GNN 的确定性等变性应在评估模式下讨论，训练时 dropout 抽样会带来逐次差别。
- 相对位置边属性具有平移不变性，但整体模型同时编码本车绝对位置的标准化值，不能宣称整体严格平移不变或旋转不变。
- 时间顺序不是可任意置换的维度；GPT-2 的因果结构及位置编码保留了历史先后。

现有 `project/experiments/qgat_relation/check_graph.py:1` 和 `project/reports/qgat_relation/graph_checks.json:1` 已验证：

1. 新增权重为零时，新 D 与同共享权重原 D 的原始/最终读出误差约 `1.33×10⁻¹⁵`，共享参数与输入梯度最大误差约 `3.20×10⁻¹⁴`。
2. 新增权重非零时，局部态精确收缩与独立完整 7 比特线路输出最大误差约 `2.55×10⁻¹⁵`，全部输入/参数梯度最大误差约 `7.82×10⁻¹⁴`。
3. 零初始化的新增通路有有限非零梯度；固定标准化节点特征、只干预合法物理速度时，最终读出确实改变。
4. 车辆换序、空帧、非连续有效掩码、无效 NaN 槽及其梯度、45 米边界、自环、近零后选择等检查通过。

这些检查证实实现一致性、可微性和若干输入契约，不证明相关结构能提升 ADE/FDE，也没有证明实际训练后仍有效使用所有关系通道。不要重新把“量子梯度被截断”“关系加在输出后”“旋转相互抵消”作为已有事实；若提出此类新怀疑，需要针对当前代码或实际权重给出具体证据。

## 8. 请 GPT-6-Pro 重点回答的模型问题

以下是待分析的问题，不是已经确认的缺陷，更不是预先指定必须实施的改进：

1. **关系仅改匹配是否足够？** 当前新 D 的 `R(e_ij)` 改变 `gamma_ij`，V 仍只依赖发送车辆。请分析哪些交互模式能够由这种机制表达，哪些可能需要接收者相关的消息内容；不要只用“边信息已经加入”替代功能分析。
2. **读出是否保留了任务需要的差异？** 混合读出与相干读出各保留了什么，是否存在冗余、相消、归一化后尺度丢失，或少数邻居主导？32→128 线性读出能否区分对预测关键的运动关系？已有随机数值测试不等于真实数据上的信息充分性。
3. **一次传播与两层四头的差别是否关键？** 请区分邻域范围、传播轮次、多个交互通道和残差保留各自的作用；如建议加层或多头，应给出明确的信息路径及最小验证，不能只因经典 GNN 更大就直接照搬全部容量。
4. **量子编码和核结构存在什么限制？** 共享六角度编码、固定 CNOT、分支末端局部 U3，以及新增的局部关系旋转共同形成怎样的匹配族？需要检查可辨识性、角度饱和、重参数化冗余和实际状态分布，而不是把比特数增加直接等同于容量有效增加。
5. **图支路是否被公共时序模型充分利用？** 数值 token 同时有本车状态直达通路。图读出幅度、LayerNorm、768 维线性投影和相加融合，是否让交互信号被忽略或混淆？需要用证据区分“图没表达出来”和“表达出来但下游没用好”。
6. **怎样解释最优点与最后一轮的相反排序？** 结构建议应同时解释现有两种取点结果，并查看逐场景、逐 SNR 的误差分布。不要只挑新 QGAT 更好或更差的一张表，更不要把单种子微小差距当稳定优劣。

希望给出的结论按“已确认的结构事实 → 能改变决策的疑点 → 有针对性的最小结构候选 → 匹配对照如何证伪”组织。优先在当前任务、数据、感知输入和公共时序接口内改进量子图模块。经典 GNN 作为固定强参照，不删除边属性、不减少层数、不缩短其学习预算。后续结构对照要保持对称的数据暴露、训练预算和检查点选择规则；本次不要求以训练设置搜索为主要答案。

若主张某种量子机制本身有价值，应说明它与使用相同关系输入的经典替代相比新增了什么可检验能力。现阶段不预设量子优势一定存在，也不把“暂时没有明显领先”直接等同于量子模块没有研究价值。

```python
"""D QGAT with directed physical relations controlling its query rotations."""
import math
import torch
from torch import nn
import pennylane as qml

from experiments.qgat_factorial.graph import FactorialGraph, two_unitary, pauli_observables
from prediction.classical import _source

# Use the same function object as the strong GNN, including its SI scales.
build_edge_features = _source.build_edge_features


def relation_rotation(phi, wires):
    """On each attention qubit apply RY first, then RZ."""
    for k, wire in enumerate(wires):
        qml.RY(phi[..., 2*k], wires=wire)
        qml.RZ(phi[..., 2*k+1], wires=wire)


def relation_matrix(phi):
    """Exact batched RZ RY tensor RZ RY, retaining complex128 gradients."""
    flat = phi.reshape(-1, 4)
    gates = [qml.matrix(qml.RZ(flat[:, 2*k+1], wires=0)) @
             qml.matrix(qml.RY(flat[:, 2*k], wires=0)) for k in range(2)]
    return torch.einsum('...ab,...cd->...acbd', *gates).reshape(*phi.shape[:-1], 4, 4)


class RelationGraph(FactorialGraph):
    def __init__(self):
        super().__init__(qubits=2, radius=45)
        # Keep downstream shared initialization identical under the same seed.
        with torch.random.fork_rng(devices=[]):
            self.edge_encoder = nn.Linear(7, 4, bias=False)
        nn.init.zeros_(self.edge_encoder.weight)

        @qml.qnode(qml.device('default.qubit', wires=7, shots=None),
                   interface='torch', diff_method='backprop')
        def full_circuit(angles, query, index_state, theta, phi):
            qml.StatePrep(index_state, wires=[0, 1, 2])
            two_unitary(query, theta[0], [3, 4])
            for j in range(8):
                controls = [(j >> bit) & 1 for bit in (2, 1, 0)]
                qml.ctrl(relation_rotation, control=[0, 1, 2], control_values=controls)(
                    phi[..., j, :], [3, 4])
                qml.ctrl(qml.adjoint(two_unitary), control=[0, 1, 2], control_values=controls)(
                    angles[..., j, :], theta[1], [3, 4])
                qml.ctrl(two_unitary, control=[0, 1, 2], control_values=controls)(
                    angles[..., j, :], theta[2], [5, 6])
            return qml.state()
        self.full_circuit = full_circuit

    def relation_angles(self, physical, current):
        """For cleaned [B,N,4] states return phi[i,j] and D's neighbor mask.

        Only existing nonself edges within 45m rotate. Self edges retain R=I.
        All relation inputs are current/historical physical state estimates.
        """
        edges, distances = build_edge_features(physical[..., :2], physical[..., 2:])
        pairs = current[:, :, None] & current[:, None, :] & (distances <= self.radius)
        nonself = ~torch.eye(current.shape[-1], device=current.device, dtype=torch.bool)
        active = pairs & nonself[None]
        edges = torch.where(active[..., None], edges, 0)
        phi = math.pi * torch.tanh(self.edge_encoder(edges.to(self.edge_encoder.weight.dtype)))
        return torch.where(active[..., None], phi, 0).to(torch.float64), pairs

    def features(self, state_hat, standardized_state, track_exists, detected, reference=False):
        shape = standardized_state.shape
        if shape[-1] != 4 or not 1 <= shape[-2] <= 8 or state_hat.shape != shape:
            raise ValueError('Expected matching physical/standardized [...,1..8,4] states')
        if track_exists.shape != shape[:-1] or detected.shape != track_exists.shape:
            raise ValueError('Mask shape mismatch')
        m = track_exists.bool()
        z = torch.where(m[..., None], standardized_state, 0)
        physical = torch.where(m[..., None], state_hat, 0)
        if not torch.isfinite(z).all() or not torch.isfinite(physical).all():
            raise ValueError('Nonfinite valid state')
        if (detected.bool() & ~m).any():
            raise ValueError('Detected without track')
        inp = torch.cat((z, m[..., None].to(z), detected[..., None].to(z)), -1)
        a = math.pi * torch.tanh(self.encoder(inp.to(self.encoder.weight.dtype)))
        n = shape[-2]
        a = a.reshape(-1, n, 6).to(torch.float64)
        m = m.reshape(-1, n)
        phi, pairs = self.relation_angles(physical.reshape(-1, n, 4), m)
        theta = self.theta.to(torch.float64)
        batch = len(a)
        if reference is False:
            q, k, v = [self.local_state(a.reshape(-1, 6), t).reshape(batch, n, 4) for t in theta]
            # i is the receiver, j the sender: gamma[i,j] = <K_j|R_ij|Q_i>.
            rotated_query = torch.einsum('bijde,bie->bijd', relation_matrix(phi), q)
            gamma = torch.einsum('bjd,bijd->bij', k.conj(), rotated_query)
            unnormalized = gamma[..., None] * v[:, None] * pairs[..., None]
            unnormalized = unnormalized / pairs.sum(-1).to(a.dtype).clamp_min(1).sqrt()[..., None, None]
        elif reference == 'full':
            neighbors = torch.nn.functional.pad(a, (0, 0, 0, 8-n))[:, None].expand(batch, n, 8, 6)
            rotations = torch.nn.functional.pad(phi, (0, 0, 0, 8-n))
            masks = torch.nn.functional.pad(pairs, (0, 8-n))
            prep = masks.to(a.dtype)
            prep = prep + (~masks.any(-1))[..., None] * torch.nn.functional.one_hot(
                torch.tensor(0, device=a.device), 8)
            prep = prep / prep.sum(-1, keepdim=True).sqrt()
            state = self.full_circuit(neighbors.reshape(-1, 8, 6), a.reshape(-1, 6),
                                      prep.reshape(-1, 8), theta, rotations.reshape(-1, 8, 4))
            unnormalized = state.reshape(batch, n, 8, 4, 4)[:, :, :n, 0, :] * pairs[..., None]
        else:
            raise ValueError('reference must be False or full')
        probability = unnormalized.abs().square().sum((-1, -2))
        usable = probability > 1e-12
        amplitude = unnormalized / torch.where(usable, probability, 1).sqrt()[..., None, None]
        result = pauli_observables(amplitude, pairs, probability)
        result = torch.where(usable[..., None], result, 0) * m[..., None]
        return result.reshape(*shape[:-1], self.raw_dim)
```

```python
"""Four-cell QGAT experiment: one/two state qubits and all/45m neighbors."""
import math
import torch
from torch import nn
import pennylane as qml
from experiments.qgat_candidate.graph import QGATGraph, encode, unitary, observables


def two_unitary(angles, theta, wires):
    for i, wire in enumerate(wires):
        encode(angles[...,3*i:3*i+3], wire)
    qml.CNOT(wires=wires)
    for i, wire in enumerate(wires):
        qml.U3(theta[i,0],theta[i,1],theta[i,2],wires=wire)


def pauli_observables(amplitude, mask, probability):
    """15 mixed + 16 coherent Pauli expectations + postselection probability.

    Pauli order is lexicographic I,X,Y,Z tensor I,X,Y,Z; mixed excludes II.
    Coherent state is the uniform-index projection, not a classical mixture.
    """
    one=amplitude.new_tensor([[[1,0],[0,1]],[[0,1],[1,0]],
                              [[0,-1j],[1j,0]],[[1,0],[0,-1]]])
    paulis=torch.stack([torch.kron(p,q) for p in one for q in one])
    mixed=torch.einsum('...jd,pde,...je->...p',amplitude.conj(),paulis,amplitude).real
    coherent=amplitude.sum(-2)/mask.sum(-1).to(amplitude.real.dtype).clamp_min(1).sqrt()[...,None]
    coh=torch.einsum('...d,pde,...e->...p',coherent.conj(),paulis,coherent).real
    return torch.cat((mixed[...,1:],coh,probability[...,None]),-1)


class FactorialGraph(QGATGraph):
    def __init__(self, qubits=1, radius=None):
        if qubits not in (1,2) or radius not in (None,45):
            raise ValueError('Factorial graph requires qubits=1/2 and radius=None/45')
        if qubits==1:
            super().__init__()
        else:
            nn.Module.__init__(self)
            self.encoder=nn.Linear(6,6)
            self.theta=nn.Parameter(torch.empty(3,2,3).uniform_(-.3,.3))
            self.readout=nn.Sequential(nn.Linear(32,128),nn.LayerNorm(128))
            @qml.qnode(qml.device('default.qubit',wires=2,shots=None),interface='torch',diff_method='backprop')
            def local_state(angles,theta):
                initial=torch.zeros((*angles.shape[:-1],4),dtype=torch.complex128,device=angles.device)
                initial[...,0]=1
                qml.StatePrep(initial,wires=[0,1])
                two_unitary(angles,theta,[0,1])
                return qml.state()
            self.local_state=local_state
        self.qubits,self.radius=qubits,radius
        self.raw_dim=8 if qubits==1 else 32
        self.output_dim=128
        att=list(range(3,3+qubits));val=list(range(3+qubits,3+2*qubits))
        def apply(a,t,wires):
            if qubits==1: unitary(a,t,wires[0])
            else: two_unitary(a,t,wires)
        @qml.qnode(qml.device('default.qubit',wires=3+2*qubits,shots=None),interface='torch',diff_method='backprop')
        def full_circuit(angles,query,index_state,theta):
            qml.StatePrep(index_state,wires=[0,1,2])
            apply(query,theta[0],att)
```

```python
"""Five-qubit QCGAT adaptation for permutation-equivariant vehicle prediction.

Source: Li et al., MLST 7 (2026) 015007, doi:10.1088/2632-2153/ae32dd.
Shared 6->3 angle encoder, independent Q/K/V U3 gates, attention postselection.
Eight invariant observable features replace the paper's index-sensitive density
flattening. This is an adaptation, not a reproduction of its classification head.
"""
import math
import torch
from torch import nn
import pennylane as qml


def encode(a, wire):
    qml.RY(a[..., 0], wires=wire)
    qml.RX(a[..., 1], wires=wire)
    qml.RY(a[..., 2], wires=wire)


def unitary(a, theta, wire):
    encode(a, wire)
    qml.U3(theta[0], theta[1], theta[2], wires=wire)


def one_qubit_state(a, theta):
    """Independent differentiable analytic reference to the gate sequence."""
    dtype = torch.complex128 if a.dtype == torch.float64 else torch.complex64
    x = torch.stack((torch.ones_like(a[..., 0]), torch.zeros_like(a[..., 0])), -1).to(dtype)
    for angle, axis in zip(a.unbind(-1), ('y', 'x', 'y')):
        c, s = torch.cos(angle/2), torch.sin(angle/2)
        v0, v1 = x.unbind(-1)
        x = (torch.stack((c*v0-s*v1, s*v0+c*v1), -1) if axis == 'y'
             else torch.stack((c*v0-1j*s*v1, -1j*s*v0+c*v1), -1))
    t, p, l = theta.unbind(-1)
    c, s = torch.cos(t/2), torch.sin(t/2)
    x0, x1 = x.unbind(-1)
    return torch.stack((c*x0-torch.exp(1j*l)*s*x1,
                        torch.exp(1j*p)*s*x0+torch.exp(1j*(p+l))*c*x1), -1)


def observables(amplitude, mask, probability):
    """Normalized index+value amplitudes -> 3 mixed + 4 coherent + success."""
    def bloch(v):
        a, b = v.unbind(-1)
        cross = a.conj()*b
        return torch.stack((2*cross.real, 2*cross.imag, a.abs().square()-b.abs().square()), -1)
    mixed = bloch(amplitude).sum(-2)
    coherent = amplitude.sum(-2)/mask.sum(-1).to(amplitude.real.dtype).clamp_min(1).sqrt()[..., None]
    intensity = coherent.abs().square().sum(-1, keepdim=True)
    return torch.cat((mixed, intensity, bloch(coherent), probability[..., None]), -1)
```

```python
def build_edge_features(position: torch.Tensor, velocity: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
    """Return directed edge features i<-j and pairwise distances.

    Args:
        position: [B, M, 2]
        velocity: [B, M, 2]
    """
    relative_position = position[:, None, :, :] - position[:, :, None, :]
    relative_velocity = velocity[:, None, :, :] - velocity[:, :, None, :]
    distance = torch.linalg.vector_norm(relative_position, dim=-1, keepdim=True)
    direction = relative_position / distance.clamp_min(1.0)
    closing_speed = -(relative_velocity * direction).sum(dim=-1, keepdim=True)
    time_to_collision = distance / closing_speed.clamp_min(0.25)
    time_to_collision = torch.where(closing_speed > 0.0, time_to_collision, torch.full_like(time_to_collision, 20.0))
    features = torch.cat(
        [
            relative_position / 30.0,
            relative_velocity / 15.0,
            distance / 45.0,
            closing_speed / 15.0,
            time_to_collision.clamp_max(20.0) / 20.0,
        ],
        dim=-1,
    )
    return features, distance.squeeze(-1)


class DenseEdgeGraphAttention(nn.Module):
    """Multi-head graph attention using node and relative-motion edge features."""

    def __init__(self, hidden_dim: int, heads: int, dropout: float):
        super().__init__()
        if hidden_dim % heads:
            raise ValueError("hidden_dim must be divisible by graph_heads")
        self.heads = heads
        self.head_dim = hidden_dim // heads
        self.query = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.key = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.value = nn.Linear(hidden_dim, hidden_dim, bias=False)
        self.edge_bias = nn.Sequential(nn.Linear(7, hidden_dim), nn.SiLU(), nn.Linear(hidden_dim, heads))
        self.edge_value = nn.Sequential(nn.Linear(7, hidden_dim), nn.SiLU(), nn.Linear(hidden_dim, hidden_dim))
        self.output = nn.Linear(hidden_dim, hidden_dim)
        self.norm1 = nn.LayerNorm(hidden_dim)
        self.norm2 = nn.LayerNorm(hidden_dim)
        # Zero gates make a newly attached graph an exact identity mapping.  This
        # lets the graph stage start from the independently trained predictor and
        # learn only interaction corrections instead of relearning kinematics.
        self.message_gate = nn.Parameter(torch.zeros(1))
        self.feed_forward_gate = nn.Parameter(torch.zeros(1))
        self.feed_forward = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim * 2),
            nn.SiLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_dim * 2, hidden_dim),
        )
        self.dropout = nn.Dropout(dropout)

    def forward(
        self,
        nodes: torch.Tensor,
        edge_features: torch.Tensor,
        adjacency: torch.Tensor,
    ) -> Tuple[torch.Tensor, torch.Tensor]:
        batch, targets, hidden = nodes.shape
        normalized = self.norm1(nodes)
        query = self.query(normalized).view(batch, targets, self.heads, self.head_dim)
        key = self.key(normalized).view(batch, targets, self.heads, self.head_dim)
        value = self.value(normalized).view(batch, targets, self.heads, self.head_dim)
        # i receives from j: [B, i, j, heads]
        scores = torch.einsum("bihd,bjhd->bijh", query, key) / (self.head_dim ** 0.5)
        scores = scores + self.edge_bias(edge_features)
        scores = scores.masked_fill(~adjacency[..., None], -1.0e4)
        attention = torch.softmax(scores, dim=2)
        attention = self.dropout(attention)

        edge_value = self.edge_value(edge_features).view(batch, targets, targets, self.heads, self.head_dim)
        messages = value[:, None, :, :, :] + edge_value
        aggregated = (attention[..., None] * messages).sum(dim=2).reshape(batch, targets, hidden)
        nodes = nodes + torch.tanh(self.message_gate) * self.dropout(self.output(aggregated))
        nodes = nodes + torch.tanh(self.feed_forward_gate) * self.dropout(self.feed_forward(self.norm2(nodes)))
        return nodes, attention.mean(dim=-1)
```

```python
    def __init__(self, base, rank=8, alpha=16):
        super().__init__()

        self.lora_B = nn.Parameter(base.weight.new_zeros(rank, base.weight.shape[1]))

def masked_trajectory_loss(prediction, future_position, label_valid, origin_eligible):
    """Scene-normalized training ADE + 0.5 FDE; unavailable scenes contribute zero.

    This is a training denominator, not the protocol's evaluation macro average.
    Callers must skip optimizer.step when skip_optimizer is true.
    """
    if prediction.shape != future_position.shape or prediction.ndim != 4 or prediction.shape[1] != 20 or prediction.shape[-1] != 2:
        raise ValueError('Expected matching [B,20,N,2] prediction and target')
    if label_valid.shape != prediction.shape[:-1] or origin_eligible.shape != (prediction.shape[0], prediction.shape[2]):
        raise ValueError('Supervision mask shape mismatch')
    valid = label_valid.bool() & origin_eligible[:, None, :].bool()
    difference = torch.where(valid[..., None], prediction - future_position, 0)
    distance = torch.linalg.vector_norm(difference, dim=-1)
    ade_count = valid.sum((1, 2))
    fde_count = valid[:, -1].sum(1)
    ade = distance.sum((1, 2)) / ade_count.clamp_min(1)
    fde = distance[:, -1].sum(1) / fde_count.clamp_min(1)
    scene_loss = ade + .5 * fde
    return dict(loss=scene_loss.mean(), scene_ade=ade, scene_fde=fde,
                scene_loss=scene_loss, ade_count=ade_count, fde_count=fde_count,
                scenes_without_fde=(fde_count == 0).sum(),
                scenes_without_supervision=(ade_count == 0).sum(),
                skip_optimizer=bool((ade_count == 0).all()))
```

```python
def scene_metrics(prediction, future_position, label_valid, origin_eligible):
    if prediction.shape != future_position.shape or label_valid.shape != prediction.shape[:-1]:
        raise ValueError('Metric shape mismatch')
    if not torch.isfinite(prediction).all():
        raise FloatingPointError('Nonfinite model output; no scenes may be dropped')
    valid = label_valid.bool() & origin_eligible[:, None].bool()
    distance = torch.linalg.vector_norm(torch.where(valid[..., None], prediction - future_position, 0), dim=-1)
    counts = valid.sum(1)
    targets = counts > 0
    ade_count = targets.sum(1)
    fde_count = valid[:, -1].sum(1)
    target_ade = distance.sum(1) / counts.clamp_min(1)
    ade = (target_ade * targets).sum(1) / ade_count.clamp_min(1)
    fde = distance[:, -1].sum(1) / fde_count.clamp_min(1)
    return dict(scene_ade=ade, scene_fde=fde, ade_count=ade_count, fde_count=fde_count,
                loss=(ade + .5 * fde).mean(), skip_optimizer=bool((ade_count == 0).all()))


def balanced_schedule(n, seed, epoch, indices=None):
    ids = np.arange(n) if indices is None else np.asarray(indices, dtype=np.int64)
    if len(np.unique(ids)) != len(ids) or len(ids) == 0 or ids.min() < 0 or ids.max() >= n:
        raise ValueError('Origin manifest must contain unique valid origins')
    # Fixed balanced assignment, plus a cyclic rotation: every origin sees all SNRs in four epochs.
    base_order = np.random.default_rng(seed).permutation(np.sort(ids))
    offset = np.empty(n, dtype=np.int64)
    offset[base_order] = np.arange(len(ids)) % 4
    order = np.random.default_rng(np.random.SeedSequence([seed, epoch, 710])).permutation(ids)
    return order, np.asarray(SNRS)[(offset[order] + epoch) % 4]

def configure_phase(model, phase, graph_lr):
    if phase not in ('warmup', 'adapt', 'joint'):
        raise ValueError('Unknown phase')
    groups = {}
    for name, param in model.named_parameters():
        base = '.llm.' in name and 'lora_' not in name
        graph = name.startswith('graph.') or 'graph_projection.' in name
        active = not base and (phase == 'joint' or (phase == 'adapt' and graph) or (phase == 'warmup' and not graph))
        param.requires_grad_(active)
        if active:
            lr = graph_lr if name.startswith('graph.') else (3e-5 if 'lora_' in name else 1e-4)
            wd = 0. if param.ndim < 2 or (name.startswith('graph.') and hasattr(model.graph, 'forward_history')) else .01
```
