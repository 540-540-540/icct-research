# 结果与证据边界

核验日期：2026-09-13。以下数值来自服务器现存正式结果、逐轮历史和逐场景验证记录；本次整理没有训练模型、运行 GPU、重新预测或重算 bootstrap。文中路径均为交接包内路径。

当前结论：关系旋转版新 QGAT 在40轮配对实验中优于原 D；与 GNN 的100轮比较则随取点口径改变方向。按各自最佳 J，新 QGAT 的 J 高 0.799349%；在共同第100轮，新 QGAT 的 J 低 1.210823%。现有证据支持继续研究模型差异，尚不能确立新 QGAT 稳定优于 GNN，也不能把差距直接归因于量子结构。

## 3. 实验继承关系与混杂因素

| 运行 | 起点和继承关系 | 已完成更新次数 |
|---|---|---:|
| original_D40 / relation_D40 | 两组从相同种子2026重新初始化；共有图参数、时间模块初值配对；新关系模块零初始化 | 各13880 |
| gnn_fast40 | 独立从头训练，不加载旧 GNN 训练权重或优化器；时间模块初值与 D 对照一致 | 13880 |
| GNN100 | 从 gnn_fast40 的第40轮 latest 继承模型、完整 AdamW、随机状态及40条历史 | 累计34700，新增20820 |
| relation_D100 | 从 relation_D40 的第40轮 latest 继承同类完整状态；同时保留第39轮 best | 累计34700，新增20820 |

已逐项确认两份100轮 history 的前40条与对应父 history 完全相同。GNN100 与 GNN40、新 QGAT100 与新 QGAT40不能算作不同种子、不同重复或相互独立的结果。

执行方式也在继承点变化：

- GNN前40轮由两卡 DataParallel 共同训练，每卡8个样本；后60轮由物理GPU0单卡处理16个样本，继承原GPU0随机流，原GPU1流留在父断点中。
- 新 QGAT前40轮单卡 micro-batch=1；后60轮仍用物理GPU1，但改为 micro-batch=8、每完整批次累积2次。验证批次由1改为128；GNN验证批次保持32。
- 总 batch=16、样本/SNR调度、学习率、优化器规则和数值精度保持；每轮347次更新，尾批13。物理分组会改变 Dropout 随机数分配和浮点运算方式，不能称为旧执行方式的逐位延续。

[100轮协议](project/reports/qgat_extend100/PROTOCOL.md)、[配置](project/configs/qgat_extend100.json)和[继承入口](project/experiments/qgat_relation/run_extend100.py)记录了这些边界。[批量测试报告](project/reports/qgat_relation_batch_benchmark/REPORT.md)只用于解释运行配置背景：确定性一致性检查和三套后续随机流短程探针不是三次从头训练，也不是完整100轮非劣性证明。

可训练参数量：GNN 925492；原 D 610276；新 QGAT 610304。新 QGAT 对原 D 只增加28个参数，但 GNN 与 QGAT并非等参数量结构。相同总轮数或更新数不等于相同计算量；训练耗时还受分批、双卡/单卡、验证和写盘影响。参数较少、运行较快/较慢、训练损失较低，都不能单独解释预测差异的模型因果，更不能证明量子优势。

## 4. 后期趋势：完成100轮不等于证明收敛

以下为现有 history 中连续10轮的验证 J 算术平均，保留6位小数；只是单次训练曲线的描述，不是独立重复的均值或显著性检验。

| 轮次窗口 | GNN平均J | 新 QGAT平均J |
|---|---:|---:|
| 61–70 | 1.155469 | 1.153494 |
| 71–80 | 1.154139 | 1.154990 |
| 81–90 | 1.139894 | 1.140881 |
| 91–100 | 1.133722 | 1.139246 |

GNN最佳J出现在第97轮，最后10轮均值仍低于前10轮；这不能支持“早已进入明确平台”。新 QGAT最佳在第85轮，91–100轮均值较81–90轮仅小幅下降，同时仍有逐轮波动，不能仅凭最佳轮较早就断言收敛或过拟合。两组训练损失的10轮均值仍下降：GNN从81–90轮的0.989802降至91–100轮的0.949960；新 QGAT从1.090094降至1.059414。训练损失下降也不等于泛化改善。

第100轮J分别比各自最佳高2.586302%（GNN）和0.540494%（新 QGAT）。这解释了“最佳点”和“最终轮”比较不同，但不能证明新 QGAT跨种子更稳定。

两份 summary 的 sufficiency_unresolved=false 不能作为收敛证明。该字段在[共享训练器](project/prediction/training.py)中只计算“到达目标轮数且 stale==0”；当前false只说明最终轮没有刷新最佳J，不包含曲线平台、多种子稳定性或统计收敛判断。

## 5. 指标定义、样本覆盖及可分析范围

预测包含20个未来位置点，间隔0.1秒，覆盖未来2秒。目标须在历史末时刻存在且20个历史时刻中至少出现3次；计分再与未来标签有效掩码相交。定义见[时间预测器](project/prediction/temporal.py)和[评估实现](project/prediction/training.py)。

验证时，ADE先对每辆合格车的有效未来时刻求平均，再在场景内等权平均车辆；FDE只使用最终未来时刻有有效标签的合格车。随后在每档SNR内等权平均可计分场景，最后对5/10/15/20 dB四档宏平均。选点用这个验证 J。

训练损失的ADE权重略有不同：masked_trajectory_loss 在每个场景内直接平均全部有效“车辆×未来时刻”点，再平均场景；验证 scene_metrics 则先平均每车有效时刻，再平均车辆。若车辆有效未来时刻数不同，两种权重不完全一致。这是代码定义事实，现有结果没有诊断其是否限制模型表现。

已核验上表全部最佳/最终检查点对应的验证记录：

- 每份1600行，来自同样400个 origin（0–399）×4档SNR，每档400行。
- 各模型、各取点的行顺序、origin/SNR身份、ADE/FDE计分目标数一致；无缺失ADE或FDE。每行计分目标数为3–8。
- 对应验证 JSON 的ADE/FDE/J与所引用 history 行一致。

1600行不是1600个独立场景：同一origin被四种噪声条件重复评估；400个origin本身也未被现有汇总证明相互独立，连续轨迹或重叠窗口可能带来相关性。本包不把这些行数当作多种子样本量，也不据此给出独立同分布的显著性结论。

per_scene 记录只有 origin、snr_db、场景ADE/FDE和计分目标数，适合现有检查点之间按相同行配对查看误差差异；它不包含逐车、逐未来时刻的残差、场景交互标签或实际预测轨迹。仅据此不能确定误差来自哪类交互、哪辆车或哪段预测时域。

## 6. 交给模型改进分析时应保持的证据边界

当前正式证据是单种子2026、同一400-origin V_select上的开发比较。V_select同时用于每轮选点、运行配置探索及模型方向判断，不能当成未参与选择的独立评估集。相关运行报告均记录 confirmation_opened=false、test_opened=false；本次整理也未读取 V_confirm/test，未形成独立确认、多种子或统计显著性证据。

当前结果可以支持“关系旋转在本次40轮原 D 配对对照中降低误差”，以及“两个模型在续训后各自取得更低的开发集最佳J”。它尚不能支持“新 QGAT在充分训练后稳定胜过强GNN”“量子模块造成了优势”或“参数量/速度差别解释了排名”。参数量、信息路径、归纳偏置等可以作为后续模型分析的假设，现有数值不能直接替代因果消融。
