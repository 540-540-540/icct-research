# RAJ QGNN：当前唯一量子主方案

## 冻结范围

本目录只把 `RajWeightedMultiJQGNNCore` 作为量子主模型。它同时运行 `j=2` 与 `j=3` 两条高阶子集分支，并通过逐目标门控融合为 64 维图特征。论文中的主要公平对照是 `RajMultiJJohnsonCore`；两者使用相同的历史编码、二元/三元子集提升、融合器、Motion-Token GPT-2、训练样本、初始化和优化协议。

旧 PennyLane 适配器、单分支 RAJ、paper-math 重建、row-local、adaptive/finalists 及其失败日志已经从当前树中删除。它们仍可通过 Git 历史追溯。

## 数据流

1. `OwnHistoryEncoder` 编码每辆车 20 帧位置和速度。
2. `physical_graph` 计算距离、闭合速度、最近接近时间与距离等历史可观测关系。
3. `SubsetFeatureBuilder` 构造所有二元组和三元组，把节点统计与组内边统计编码为子集状态。
4. 量子分支使用图条件的 Johnson 哈密顿量进行子集间复数幺正演化，再用固定粒子数 compound evolution 和逐层数据重上传更新嵌入态。
5. 各子集的复数状态按成员关系读回到每辆车，融合 `j=2` 和 `j=3` 后形成 64 维交互特征。
6. Motion-Token GPT-2 将车辆自身运动 token 与交互特征结合，输出未来 20 步轨迹。

这里的“量子”是可微复数态矢量/哈密顿量模拟，不是量子硬件执行，也不是 PennyLane QNode。它保持了幺正演化、复振幅与固定粒子数子空间这些量子结构，但当前实验只能支持“量子结构归纳偏置”的论述。

## 已有验证结果

所有数字来自验证集，未使用测试集。

最新公平对照把经典 Johnson 图核心缩至 hidden=42。它有 125,697 个参数，量子图核心有 126,535 个参数，差异仅 838（0.66%）。二者共享数据索引、历史编码器、LLM、LoRA、接口层、初始化种子和训练协议。

| 训练规模 | ADE 改善 | FDE 改善 | J 改善 | 结论 |
|---:|---:|---:|---:|---|
| 1000，seed 2026 | -1.223% | -1.500% | -1.362% | 数据不足，量子结构未学稳 |
| 2000，seed 2026 | -3.815% | -3.514% | -3.660% | 数据不足，经典模型更好 |
| 4096，seed 2026 | 3.396% | 3.478% | 3.439% | 等参数下三项均提升 |
| 4096，seed 2027 | 0.574% | 0.371% | 0.469% | 独立初始化下方向复现 |
| 4096，两种子均值 | **1.988%** | **1.919%** | **1.952%** | 整体提升有随机波动 |

4096 样本的交互分层仅使用输入历史中的 `max_pair_risk`，阈值在 0 dB 输入上预先固定，与预测误差无关。最高风险 10% 场景中，两种子平均 ADE/FDE/J 分别改善 **4.599%/3.791%/4.177%**；两个种子的 J 改善分别为 4.235% 和 4.120%，种子间标准差仅 0.081 个百分点。这是当前最稳定的主结果。

固定上述 4096 样本模型，只改变 ISAC 历史量测的信噪比后，两种子平均 J 改善如下：

| SNR | 全验证集 J 改善 | 最高风险 10% J 改善 |
|---:|---:|---:|
| -10 dB | 2.698% | 4.089% |
| -5 dB | 2.052% | 2.998% |
| 0 dB | 1.952% | 4.177% |
| 5 dB | 3.476% | 3.747% |
| 10 dB | 4.061% | 4.557% |

两种子都在全部五个 SNR 的最高风险 10% 场景中取得正提升，均值范围为 2.998%–4.557%。第一种子呈现随 SNR 增强的趋势，第二种子没有单调趋势，因此论文不能声称“信噪比越高，量子优势越大”。可重复的通信场景结论是：RAJ 的复数幺正高阶交互建模在多种量测质量下都更适合高风险、多车强交互场景。

## 冻结测试集结果

完成上述模型选择后，固定架构、训练轮数、两个种子的检查点、0 dB 主条件和验证集输入风险阈值，对测试集执行了一次评估。测试集有 2086 个场景。

| 测试范围 | ADE 改善 | FDE 改善 | J 改善 |
|---|---:|---:|---:|
| 全部场景，两种子均值 | **3.006%** | **3.307%** | **3.161%** |
| 最高风险 20% | 3.154% | 2.682% | 2.910% |
| 最高风险 10% | **4.418%** | **4.144%** | **4.276%** |

全部场景中，seed 2026 和 seed 2027 的 J 改善分别为 3.154% 和 3.169%，种子间标准差仅 0.011 个百分点；测试集整体优势具有很好的重复性。最高风险 10% 的 J 改善分别为 5.078% 和 3.463%，两种子都保持正提升。

在 4096 样本、seed 2026 下，量子方案相对 GIN 的 ADE/FDE/J 改善为 12.550%/7.484%/10.005%，相对 PPGN 为 10.893%/4.231%/7.573%。这些较大的数字不能单独证明量子优势，因为 GIN、PPGN 与 RAJ 使用的高阶结构不同；量子主张应以 matched Johnson 对照为准。

历史结果中的 Johnson-64 图核心有 179,201 个参数。当前主对照固定为 Johnson-42，用于排除模型容量这一替代解释。

## 运行

快速结构检查：

```bash
python scripts/check_raj_qgnn.py
```

4096 样本公平训练：

```bash
python scripts/train_raj_qgnn.py --kind quantum --train-limit 4096 --epochs 20 --batch-size 32 --seed 2026 --run-dir runs/raj_qgnn/quantum_seed2026
python scripts/train_raj_qgnn.py --kind matched_classical --classical-hidden 42 --train-limit 4096 --epochs 20 --batch-size 32 --seed 2026 --run-dir runs/raj_qgnn/classical_seed2026
```

## 能否带来提升

此方案已经在 4096 样本、等参数条件下得到两种子平均 1.95% 的整体综合改善，以及高风险 10% 场景 4.18% 的稳定改善。它不支持原先“样本越少越有优势”的假设，因为 1000 和 2000 样本上量子模型反而较差。更准确的机制解释是：RAJ 需要足够样本估计高阶复数交互；训练充分后，它在复杂车辆交互条件下形成了经典等参数核心未能达到的归纳偏置。

当前架构、训练轮数、SNR 条件和交互阈值已经冻结，单次测试集评估也已完成。后续不得根据测试结果继续调参。论文主表应报告测试集全部场景的 3.16% J 改善，并以高风险 10% 场景的 4.28% J 改善说明 QGNN 在通信高交互场景中的特殊价值。
