# DESIGN.md — 三基站多目标 ISAC 前端 V1 总体设计

（面向非通信背景读者；数学细节见 `SYSTEM_MODEL.md`，接口见 `INTERFACE_SPEC.md`。）

## 1. 为什么重构

SENS-AUDIT-01 证实：当前给 GNN/QGNN 用的 sensing 缓存**不是多目标 ISAC 感知**，而是
"已知目标逐个单独估计再摆回车位"：每辆车有自己的发射波形、自己的接收信号、自己的噪声；
检测步骤不存在（`detected` 恒等于"真值里这辆车存在"）；目标数量、身份、对应关系在估计前
已由真值给出；5–20 dB 因此不影响结果。上游于是只能提供"理想感知"，下游任何鲁棒性结论
都不成立。

本设计把这个上游改成一条**物理可信、可复现、不会成为下游瓶颈**的 3-BS 感知链，
不追求 SOTA，只要求每个部件可解释、可测试、不易泄漏真值。

## 2. 目标数据流（一句话版）

```text
3 个固定基站，每站每 0.1 秒收到"所有车辆回波叠加成的一份信号"
        ↓  检测（自己数目标，不借助真值）
每站得到若干匿名"点"（距离、角度、径向速度）
        ↓  跨站配对 + 位置融合
融合后的匿名位置点
        ↓  恒速卡尔曼滤波
匿名航迹 [x_hat, y_hat, vx_hat, vy_hat]，映射到固定 8 个输出槽
        ↓
现有 GNN / QGNN（接口不变）
```

## 3. 部件说明（白话）

1. **共享回波模拟器**（A 域）：每站把该站能看到的全部车辆回波先相加，再加一次接收机噪声。
   车辆离得越远回波越弱（1/距离⁴），不同车/不同站强度天然不同；不再"每辆车都一样强"。
2. **检测器**（B 域）：每站先在距离-多普勒二维图上用 CFAR 找显著峰，再只对这些峰做角度（AoA）
   估计，得到匿名"点"。"有几辆车"完全由峰值数量决定；弱目标被漏掉、噪声偶尔造出虚警，
   都是正常且被统计的现象。
3. **跨站关联融合**（B 域）：每站的点换算到同一坐标系后按统计门限配对；
   两三个站看到同一个目标就做加权平均，位置更准。只有一个站看到时也保留，但置信度更低。
4. **跟踪器**（B 域）：恒速卡尔曼滤波平滑位置并给出速度。航迹有完整生命周期：
   出生（试探）→ 确认 → 漏检短时滑行（coast）→ 删除。只有确认的航迹会输出。
5. **8 槽接口**（B 域）：内部航迹有匿名编号；确认时分配一个固定输出槽（0–7），
   死亡后回收。下游看到的仍是熟悉的 `[20帧, 8槽, 4维]` 结构。
6. **标签构造**（C 域）：感知全部结束、缓存封存之后，离线把匿名航迹与真值车辆按历史轨迹
   匹配，再挂上未来轨迹作为监督标签。真值只在这里出现，绝不回写感知状态。

## 4. 关键冻结选择（详见 `DECISIONS.md`）

| 主题 | 选择 | 一句话理由 |
|---|---|---|
| 回波组织 | 每站一份 `[16阵列,256子载波,256符号]` 共享张量，先求和后加噪 | 直接消除审计中的 A/B/C 失败根因 |
| AoA | **采用**：每站 16 元均匀线阵，FFT/Bartlett 扫描（不用 MUSIC） | 每站直接得到局部 (x,y)，跨站配对变成简单空间门控；NIST/旧码都有可复用实现 |
| 波形 | 沿用冻结的 24 GHz / 93.1 MHz / 256×256 / T=12.375 µs | 距离分辨率 1.61 m、无模糊距离 412 m，覆盖现有场景；不引入新不确定 |
| 功率/SNR | 雷达方程简化：固定车辆 RCS + 1/r⁴；控制变量 `snr_ref`（100 m 处逐 entry SNR）；每站一份单位方差噪声 | 废除"每目标同 SNR"；per-target 差异自然出现 |
| 检测 | 2D Range-Doppler CA-CFAR + NMS + 逐峰 AoA；目标数来自检测；DBSCAN 暂不做 | 比全尺寸 3D CFAR 便宜约一个量级，仍保留真实检测与 AoA |
| 跨站 | 顺序 Hungarian grouping（BS0↔BS1 → groups↔BS2）+ 逆协方差融合 | 唯一、确定性、可编码；无需 PHD/MHT |
| 测量协方差 | 离线 calibration LUT（σ_r/σ_u 按 peak-to-noise 分箱）+ Jacobian 传播 | 关联/融合/KF 的 R 必须有可追溯来源，不能临场拍常数 |
| 速度 | 位置序列进恒速卡尔曼滤波 | 简单、可测；径向多普勒留作 V1.1 备选 |
| 航迹确认 | 3 帧内 ≥2 次更新，且至少 1 次来自 ≥2 站融合 | 单站虚警不能自证成航迹 |
| 槽位 | 确认时分配、死亡回收（冷却 10 帧）、超 8 个按非真值评分淘汰 | 不用真值排槽，保持 8 槽接口 |
| 监督 | 离线 track↔GT 匹配（历史平均距离 + Hungarian） | 真值只用于生成与事后标签/评估 |
| SNR 档位 | **不继承、不预冻结**：先做宽范围校准 sweep | `[5,10,15,20]` 是旧错误的产物，必须重选 |
| 数据路径 | 新 `data/f01e` + 新 config；旧 `data/f01d` 冻结为 oracle 基线 | 不覆盖历史，支持"理想 vs 真实"对比 |

## 5. 复用哪些现有资产

- 保留：NGSIM 场景构建、划分、3-BS 几何、0.1 s 时间网格、下游输入契约（
  `state_hat/track_exists/detected/timestamp`）、打包/loader/归一化框架。
- 复用算法（重写为 Python/CUDA）：旧 `ofdm_echo` 的"求和+统一噪声"数学；
  旧 `detector.py` 的 CA-CFAR/NMS/插值（主路径改为 2D RD）；旧 `tracker.py` 的航迹状态机与
  非真值 top-8 选择；NIST 5GNRad 的 2D CA-CFAR/NMS/逐峰角度扫描与关联指标模板。
- 退役主路径：`generate_symbol_gpu.py`、旧 `run_symbol_frontend.py`、
  `scripts/run_f01d_gpu.py`；旧文件保留供 F01-D 复现与 oracle 对照。
