# 师兄 R0 框架下 Raj QGNN 最终报告（2026-09-21）

## 最终结论

在 Lankershim R0 协议下，最终冻结的 **Raj 混合 QGNN** 在三个配对种子上，
测试 ADE 和 FDE 均逐一低于师兄的经典 Target Interaction GNN：

- 经典 GNN：ADE `0.620601 ± 0.000423`，FDE `1.252485 ± 0.001841`；
- Raj 混合 QGNN：ADE `0.615783 ± 0.002833`，FDE `1.238866 ± 0.009085`；
- QGNN 平均改善：ADE **0.776%**，FDE **1.087%**；
- 碰撞率从 `0.003500` 降到 `0.002833`，平均下降 **19.048%**；
- excess collision rate 平均下降 **20.796%**。

因此，当前结果支持“Raj QGNN 方案稳定优于师兄经典 GNN”，并且在安全相关的
碰撞指标上优势明显。ADE/FDE 的优势稳定但幅度不大，不能表述为大幅领先。

这也不是严格的“量子优势”证据：QGNN 参数更多，且本轮测试是在旧结构已经看过
同一测试集之后完成的工程确认，不是全新盲测。

## 冻结结构

最终模型保留师兄的完整自运动路径和两层经典局部图消息传递，并在其前方注入 Raj
高阶量子交互特征：

1. 师兄 `IndependentGRU` 历史编码、节点投影、时间嵌入和解码器；
2. Raj Weighted Multi-J 量子核心，固定为 `j=2+j=3`、三轮演化；
3. 量子结构包含复数量子态、图条件 Hamiltonian 演化、固定粒子数 compound
   evolution 和复数 1-RDM 读出；
4. 量子特征以固定非零强度 `0.05` 注入节点；
5. 两层经典局部 GNN 再传播量子条件化后的节点表示；
6. 量子投影层为 `64 -> 128 -> 128`，没有可退化为零的可学习总门控。

参数量：

| 模型 | 可训练参数 |
|---|---:|
| 师兄经典 GNN | 400,558 |
| Raj 混合 QGNN | 552,181 |

QGNN 多出约 37.85% 参数，主要来自保留完整 Raj 核心。因此本结果证明的是当前混合
QGNN 系统效果，不是容量严格匹配后的量子归因。

## 严格配对协议

- 数据：`data/multitarget_lankershim_v1.npz`；
- 任务：20 帧历史预测 20 帧未来，最多八辆车；
- 训练/验证/测试：6000 / 1200 / 1200 scenes；
- 噪声：位置 `0.35 m`，速度 `0.20 m/s`；
- 种子：2026、2027、2028；
- 两个图模型从每个种子同一个 IndependentGRU 检查点开始；
- 每个新增图模块在构造前统一重置到 `seed + 17`；
- 两组使用相同数据顺序、噪声序列、30 epoch、batch 128、LR `4e-4`；
- 检查点只按验证集 `ADE + 0.35 * FDE` 选择；
- 冻结结构后才执行三种子测试评估。

早期正式配对脚本曾遗漏“模型构造前重置随机种子”，导致新增模块初始化不真正配对；
该缺陷已在提交 `4fce793` 修复，修复前结果不作为最终证据。

## 三种子测试结果

| Seed | 经典 GNN ADE/FDE | Raj QGNN ADE/FDE | QGNN 改善 ADE/FDE |
|---:|---:|---:|---:|
| 2026 | 0.620214 / 1.254536 | 0.617746 / 1.247200 | 0.398% / 0.585% |
| 2027 | 0.621052 / 1.251946 | 0.612535 / 1.229182 | 1.371% / 1.818% |
| 2028 | 0.620538 / 1.250974 | 0.617068 / 1.240215 | 0.559% / 0.860% |
| **均值** | **0.620601 / 1.252485** | **0.615783 / 1.238866** | **0.776% / 1.087%** |

三个种子上 ADE 和 FDE 均同向胜出，不依赖单个幸运种子。

## 量子核心性检查

验证集上，将训练完成模型的量子耦合强制设为零，三个种子均退化：

| Seed | 有量子核心 ADE/FDE | 关闭量子核心 ADE/FDE | 有量子核心的改善 |
|---:|---:|---:|---:|
| 2026 | 0.571300 / 1.147405 | 0.578411 / 1.172387 | 1.229% / 2.131% |
| 2027 | 0.573901 / 1.145960 | 0.592183 / 1.198676 | 3.087% / 4.398% |
| 2028 | 0.573902 / 1.155344 | 0.585893 / 1.189232 | 2.047% / 2.850% |

同时，早期零门控版本的门值仅约 `1e-4`，实际上绕开了量子分支；该版本已经作废。
最终模型使用固定非零耦合，量子参数 L2 更新量非零，关闭量子核心后性能在三个种子上
一致下降。因此最终模型不是“挂名 QGNN”。

## GPT-2 / LoRA 阶段

将经典 GNN 和 Raj QGNN 分别接入同一套 Motion-Token GPT-2，冻结图骨干与 GPT-2
基础权重，只训练 LoRA、token/interface 和预测头，16 epoch 验证结果为：

| Seed | 经典 GNN + GPT-2 | Raj QGNN + GPT-2 | 结论 |
|---:|---:|---:|---|
| 2026 | 0.549391 / 1.103534 | 0.545162 / 1.092805 | QGNN 双指标胜出 |
| 2027 | 0.546246 / 1.101350 | 0.542995 / 1.089903 | QGNN 双指标胜出 |
| 2028 | 0.547908 / 1.105613 | 0.547714 / 1.106675 | ADE 近乎持平，FDE 略差 |

所以当前不能宣称“Raj QGNN + GPT-2 在三种子上稳定胜过经典 GNN + GPT-2”。
24 epoch 扩展没有放大优势；解冻图骨干与 LoRA 联合微调会破坏已收敛图表示，两组都
在 epoch 0 最好，故该路线淘汰。

## 失败路线与因果结论

1. **从零训练的新 Raj 解码器**：改变了时间接口，不是公平图替换，只保留为诊断。
2. **全 SinD 最优架构直接迁移**：数据和时间接口同时改变，不能回答 GNN vs QGNN。
3. **IndependentGRU + 零门控 Raj**：量子门停在约 `1e-4`，性能来自共享经典路径。
4. **固定量子耦合、纯 Raj 替换**：量子核心有效，但验证仍落后经典 GNN。
5. **一层经典 + Raj 的等参数方案**：参数几乎相等，但三种子测试平均差约
   0.30% ADE / 0.32% FDE，失败。
6. **两层经典 + Raj**：三种子图层测试全部胜出，是当前工程主方案。
7. **GPT 联合解冻图骨干**：破坏预训练图表示，失败。
8. **经典/QGNN 线性融合**：仅得到与纯 QGNN 接近的约 1% 增益，没有新的价值。

## 证据边界与下一步

当前可以说：

- Raj 混合 QGNN 在师兄 R0 图预测任务上稳定优于经典 GNN；
- Raj 量子核心对最终性能有可重复、不可绕过的贡献；
- 安全相关碰撞率改善约 19%，属于明显优势。

当前不能说：

- 硬件量子优势或 PennyLane-native 性能优势；
- 容量严格匹配的纯量子优势；
- 全新盲测上的统计显著优势；
- QGNN + GPT-2 已稳定超过经典 GNN + GPT-2。

若要形成论文级最终主张，下一步应冻结当前结构，在未参与任何结构选择的新数据切分、
新城市数据或预注册 SNR 条件上做一次真正盲测，并补充容量匹配的经典控制。
