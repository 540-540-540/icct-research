# G2 高阶交互诊断（0 dB / seed2026）

## 结论

- 显式三车联合交互没有对最强物理路由两两模型形成清晰优势。
- 因此当前 Automatum 不支持 高阶关系是主要瓶颈这一强假设。
- A-SUBSPACE 暂时降级为条件候选；C-GLOBAL 成为优先 QGNN 路线。
- 新数据集若显著提高交互密度，应重新执行同一诊断。

## 科学解释

三车联合在部分复杂场景有弱正信号，但增益只有约 1–2% ADE、不到 1% FDE，且整体 FDE 略差。按照此前冻结的准入规则，只有经典高阶模型相对强 pairwise baseline 出现稳定、实质性改善时，A-SUBSPACE 才进入主路线；当前证据未达到该标准。

当前结果仅为 0 dB / 单 seed / validation-only 诊断，不使用 test，不作为论文最终数字。
