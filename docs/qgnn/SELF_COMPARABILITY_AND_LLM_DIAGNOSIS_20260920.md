# Self 新旧可比性与 LLM 弱势诊断

来源：服务器 /home/dell/YrM/ICCT；只读取 train/val 和已有检查点，未进行优化器更新、未访问 test。

## 一、先区分中心构图与监督目标扩大

Self 不读取邻车。把同一辆车从旧图某个槽移到其独立中心槽，保持自身输入、标签、模型权重不变，不应改变其预测。
完整核对旧 val 的14,535个目标：新版目标包含全部旧键，历史状态、未来标签、时间戳最大差异均为0。
八组新旧已训练checkpoint在新目标布局中回放，旧/新各自记录的原指标均在2e-5m内复现。
因此没有证据表明改变槽位或补入邻车本身提升了Self；本轮实质还改变了目标覆盖、训练预算与目标权重。

| 项目 | 旧8车图 | 新逐目标 |
|---|---:|---:|
| train origins | 15,802 | 15,802 |
| train目标窗/epoch | 124,494 | 319,855 |
| val origins | 1,880 | 1,880 |
| val目标窗 | 14,535 | 31,211 |
| 完整batch监督目标数 | 平均252.108 | 256 |
| 完整batch涉及origins | 32 | 平均253.61 |
| 参数更新/epoch | 494 | 1,250 |
| 20epoch总更新 | 9,880 | 25,000 |

新增的是既有记录中先前未覆盖的车辆—时间窗口；train物理车辆1214→1218，val仍为146辆。不能把更多重叠车窗当作更多独立交通事件。
同一旧目标仍每epoch出现一次，并不是把它多训练2.5倍；模型总更新与总体监督曝光分别增加2.530倍、2.569倍。
两版坐标评价都先origin内车辆平均、再origins等权；变化在于每个origin的目标集合与分母，不是暗中更换为全车辆宏平均。
新train中原目标占总origin权重47.056%，新val占57.096%；其余权重属于新增目标。

## 二、同检查点交叉评价直接分解变化

TCN完整验证交叉结果（米）：

| checkpoint | 评价目标 | ADE | FDE |
|---|---|---:|---:|
| 旧模型 | 旧14,535目标 | 0.417391 | 0.911091 |
| 旧模型 | 新31,211目标 | 0.399394 | 0.856145 |
| 新模型 | 旧14,535目标 | 0.400884 | 0.884439 |
| 新模型 | 新31,211目标 | 0.376311 | 0.816700 |

旧模型不改权重，只更换评价人群，ADE改善0.017997m、FDE改善0.054945m。然后在固定新目标集合上比较新旧checkpoint，另有ADE 0.023083m、FDE 0.039445m改善。
后者是重新训练后的整体变化，混合了更多训练目标、更新次数、学习率按epoch的进程和批次相关性，不能单独归因于某一项。
若始终固定旧目标，新TCN的ADE/FDE为0.400884/0.884439；原先直接对比0.417391→0.376311会放大对同一批目标的改善印象。

## 三、当前LLM不是“只将普通Transformer替换为更大模型”

已核查的实现差异：
- GPT2Model.from_pretrained确实读取本地预训练参数。诊断逐张量比对67,736,832个冻结GPT-2参数与models/gpt2/model.safetensors，全部相等。不是随机主干误被冻结。
- 当前只保留GPT-2前4层；不是完整12层模型。注意力QKV用rank8 LoRA，LoRA可训练参数98,304；其他GPT-2主干权重固定。经典Transformer则全参数训练。
- LLM输入是1681类运动token插值、连续运动适配和本车参考系状态，不是文本输入。运动embedding从语言词嵌入等距抽行初始化，这些行没有预先学好的运动语义。
- LLM ego_v1对连续输入去除绝对全局朝向，在本车参考系预测再旋回。经典模型直接读取全局dx,dy,vx,vy；它们保留的方向先验不同。因此不能把本轮差距全部归因于Transformer/GPT-2网络家族。
- LLM还带0.035倍token CE及较小的LoRA学习率；经典模型只优化坐标损失。旧图CE按有效token等权，新版CE与坐标共同使用origin权重。这项仅影响LLM，不能解释经典baseline变化。

当前同一旧14,535目标上，新LLM为0.632918/1.391687，新TCN为0.400884/0.884439；所以LLM相对弱势确实存在，不是评价目标改变制造的假象。

## 四、短诊断排除了什么，尚不能证明什么

用训练集固定随机96目标，以及三个32目标梯度批，未更新权重：
- 关闭已训练own_history_adapter后，本批加权ADE/FDE从0.4017/0.7029升到0.8688/1.7335，预测平均变化0.737m。连续输入已被有效使用，不能说新输入支路失效。
- 关闭self_head输入中的expected_motion只改变预测约0.00539m；该已训练模型的显式token期望读出贡献较小，但这不是“从头不训练token任务”的等价消融。
- 在这三个批次，0.035CE对LoRA梯度范数约为坐标梯度的1.6%–3.4%，夹角余弦0.006–0.211；对own adapter为1.8%–4.6%，余弦0.099–0.286。未见辅助任务压过或系统反向于坐标梯度的证据。
- 将同一历史整体旋转0.8rad，LLM的旋转等变误差约1.44e-5m，TCN约0.548m。这证实两模型对全局朝向的依赖不同，不能据此量化该差异对val成绩的贡献。
- 上述是少量训练批的局部诊断，不是完整训练集/验证集指标，也不能据此排除所有训练阶段的梯度冲突。
已证实具体配置差异和LLM实际弱势，尚未识别“裁剪层数、冻结方式、坐标方向信息、预训练迁移”各自贡献。

## 五、下一步应优先隔离LLM接口与训练因素

保持当前强经典baseline原样。用同一目标集合、相同连续运动信息、相同方向可见性、相同坐标输出接口和更新预算，比较同一个GPT-2时序结构：预训练+LoRA、预训练+全参数、随机初始化+全参数；必要时补随机+LoRA形成2×2因子控制。
这一组区分预训练收益与冻结限制；运动token接入作为独立因素再比较，不一次同时改很多项，也不以LLM必须赢为目标。
长训练仍由用户启动。当前只完成诊断，没有自动开展新训练。
