## Frozen A(G) replacement

Reference paper-math A(G):
- predicts one graph-conditioned angle from the same 16D physical edge features;
- applies pairwise Givens rotations sequentially in canonical graph-derived order;
- overlapping pair rotations do not commute.

Diagnostic A_exp(G):
- use the **same angle-network architecture** per round (`Linear(16,32) -> SiLU -> Linear(32,1)`);
- use the same `theta_ab = tanh(MLP(edge_ab)) * pi/2` convention;
- lift each active node pair angle to all j-subset transitions generated by exchanging that node pair;
- assemble one real-symmetric Johnson-shell Hamiltonian H for the scene;
- apply `U = exp(i H)` once per round;
- no trainable global alpha/scale is added;
- no feature, readout, joint-mixer, loss, downstream or training change.

This keeps the edge-angle parameterisation and parameter count matched while isolating the non-commuting sequential-product versus Hamiltonian-exponential semantics.

## Correctness gates before training

Must pass:
1. output norm preservation <=1e-10 in float64 small case;
2. zero-angle identity <=1e-10;
3. node-permutation equivariance <=1e-10 on deterministic unique graph keys;
4. finite/non-zero angle-network gradients;
5. complete model forward/backward finite on SinD smoke;
6. graph parameter count exactly equals the frozen full paper-math reference (56,763);
7. test split not constructed.

If any fail, do not train.

Primary rescue:

- FDE lower than full paper-math reference;
- J improvement >=3%.

Strong rescue:
- both metrics lower;
- J improvement >=5%.

Near-no-effect:
- absolute J change <=1%.

Gap-recovery diagnostic:
- report what fraction of the frozen intermediate-vs-full J gap is recovered by A_exp(G).

If strong rescue passes, A(G) operator composition becomes the leading identified transfer-failure mechanism.
