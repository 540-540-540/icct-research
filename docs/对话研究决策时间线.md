# ICCT论文研究决策时间线

本文件按本对话中的实际研究推进顺序整理。它记录为什么改变方案，不把中间尝试改写成最终成功方案。

## 阶段1：发现量子适配器收益不足

- 初始目标是把量子模块加入已有的GNN＋LLM轨迹预测框架。
- 量子适配器ADE改善约0.14%，匹配经典适配器约0.52%。
- 明确早期Graph＋LLM的4%–6%提升与适配器边际收益属于不同实验协议。
- 决策：量子模块不能只做末端小残差，必须承担图消息传递的核心关系建模。

## 阶段2：从适配器转为完整QGNN

- 讨论并实施以QGNN替换GNN关系核心。
- 先验证单层QGNN，再测试两层都量子化。
- 旧版双层量子明显退化；分析发现两层职责重复、高维压缩到少量角度、连续量子变换形成信息瓶颈。
- 决策：保留两层传播需求，但重做物理对齐输入和层间分工。

## 阶段3：迁移到PennyLane

- 明确本机/VS Code只是代码编辑与远端控制界面，训练实际在远端RTX 4090运行。
- 使用PennyLane `default.qubit`、解析态矢量、`shots=None`，不等同于真实量子硬件。
- 确定6比特、3层、RY/RZ编码、RZ–RY–RZ可训练旋转、环形CNOT和数据重上传。
- 6比特用于承载12个关系量，每比特通过RY/RZ编码两类信息。
- GPU利用率不高属于正常现象：小量子电路模拟包含大量小算子和CPU/GPU同步，瓶颈不是显存容量。

## 阶段4：训练和测试物理对齐双层QGNN

- 使用一个训练种子2026快速排障。
- 发现LLM联合训练时解冻图骨干会破坏量子关系核。
- 改为冻结QGNN，只训练token投影、LoRA和轨迹修正头。
- 完成1200场景四SNR测试：QGNN＋LLM显著优于Plain GNN，但未超过匹配经典GNN＋LLM。
- 保存有效检查点，删除与最终结果无关的旧失败产物，只保留文字结论。

## 阶段5：分析量子优势适用场景

- 单层与双层、角度范围、纠缠、深度和数据重上传完成消融。
- 发现量子对经典的总体优势不足，但收益随交互复杂度上升。
- 结果无关分层显示：综合复杂度、闭合强度和机动强度最高10%场景中，量子ADE/FDE点估计约改善0.4%–1.4%。
- 决策：保留全体场景主结果，同时将高交互场景作为机制分析，不能只挑有利样本替代总体结果。

## 阶段6：重新定义LLM职责

- 用户指出“有无LLM差别不大”，要求QGNN与LLM不是简单叠加。
- 分析旧模型：GPT-2主要压缩历史，未来query位于Transformer外，运动词概率没有直接产生坐标。
- 实施future-token分支：未来20步进入GPT-2因果序列，运动词概率可微软解码为轨迹。
- 量子侧改善0.170% ADE/0.246% FDE，但经典侧也有相近收益，说明它是通用LLM改进。

## 阶段7：寻找QGNN与LLM的直接接口

- 尝试用QGNN注意力路由不同目标的LLM未来隐藏状态。
- 总体只改善FDE，高复杂度组出现正收益。
- 进一步使用真实消息强度\(\alpha g\)，并学习早、中、后三阶段LLM信任倍率。
- 得到当前最佳开发集0.669766/1.296094，成为冻结主方案。
- 独立确认中均匀关系略好于learned量子关系，因此不能声称量子权重已经优于简单路由。

## 阶段8：更强耦合和语义规划排障

- 自由量子关系token：注意力接近均匀，停止。
- 碰撞风险时间注意力：注意力更集中但误差没有改善，停止。
- 原始量子测量直接融合LLM状态：6轮未超过epoch 0，停止。
- 边级未来交互解码器三版：边贡献无直接监督，均未超过源模型。
- 三阶段意图Token：分类准确率约60%–65%，但坐标收益约0.004%；真实意图oracle上界也极小。
- 决策：瓶颈是缺少新的条件信息，不是接口还不够复杂。

## 阶段9：长时域与LLM组件消融

- 将预测从2秒延长到4秒，LLM相对纯QGNN只改善0.097%/0.083%，排除“预测越长LLM越有优势”的简单假设。
- 对future-token分支重新训练三项消融：去运动token、去图token、去可学习future query。
- 去图token稳定退化0.1658%/0.2395%，且几乎回到旧QGNN＋LLM起点。
- 去运动token贡献很小；去future query几乎无影响，FDE略好。
- 最终定位：QGNN图token是当前最有证据的QGNN→LLM衔接点。

## 当前决策

- 主方案保持双层物理对齐QGNN＋LLM，不更改论文核心路线。
- 方法故事聚焦“QGNN关系建模—图token条件化—LLM因果未来推理—分阶段信任融合”。
- 当前结果可以证明完整框架与两个组成模块有价值。
- 当前结果只能证明复杂交互场景中的量子优势趋势，不能证明总体显著量子优势。
- 投稿前最优先补多训练种子、最终架构图token消融、独立高交互验证和有限shots/噪声实验。
