# 第二图：量测—航迹关联图代码与最终实验记录

## 1. 当前结论

本阶段已经实现“身份未知的多基站融合量测 → 量测—航迹二部图 → 一对一关联 → 递归状态更新 → 目标交互 GNN → 运动 Token + LLM”的完整链路。

最终结果采用加入显式无匹配拒绝、协方差下限和航迹恢复后的 Stabilized Hungarian-EKF 作为公平传统基线。Association GNN 在不同 SNR、漏检率和虚警率下均表现出较好的身份保持和轨迹恢复能力；将关联结果送入已有 Graph+LLM 后，四个 SNR 下的 ADE 和 FDE 均低于 Stabilized Hungarian-EKF。

这些结果已经足以作为硕士毕业论文的第二个研究内容。当前暂不进行多随机种子实验，目标出生/消失和真实检测器量测可列入局限性与未来工作。

## 2. 输入与监督信息

- 数据集：同步多目标 Lankershim 场景缓存 `multitarget_lankershim_v1.npz`；
- 每个场景最多 8 个目标，20 帧历史、20 帧未来，采样间隔 0.1 s；
- SNR：5、10、15、20 dB；
- 在线生成身份未知的融合量测，包含漏检、泊松虚警、SNR 相关位置/速度噪声、量测协方差、置信度和 1–3 个基站可见性；
- 每帧最多 12 个量测，输入模型前随机打乱顺序。

车辆 ID 不作为节点、边或模型输入。真实 ID 只用于离线监督标签、Oracle 上界和 IDSW/IDF1 评估，因此不存在身份标签泄漏。

## 3. 模型结构

### 3.1 图节点与候选边

- 航迹节点（11维）：预测状态、预测协方差、航迹年龄、连续漏检次数和航迹置信度；
- 量测节点（14维）：融合状态、量测协方差、SNR、检测置信度、基站支持数量和三基站可见掩码；
- 候选边（10维）：位置/速度创新、欧氏距离、马氏距离、速度残差、联合不确定度、SNR 和检测置信度；
- 先通过欧氏距离或马氏距离进行门控，非候选边不参与匹配。

### 3.2 Association GNN

航迹节点与量测节点构成二部图。网络使用两层双向消息传递：航迹从候选量测聚合信息，量测也从竞争航迹聚合信息。边分类头输出关联概率，dustbin 分支表示漏检或无匹配，同时输出归一化关联熵。

关联概率最终经过一对一 Hungarian 解码，保证一个量测最多分配给一条航迹。Edge MLP 使用相同节点和边特征但不进行图消息传递，用作图结构消融。

### 3.3 Stabilized Hungarian-EKF

最终传统基线包含三项稳定化机制，均不使用真实车辆身份：

- 显式无匹配拒绝：平方马氏距离大于 16 时拒绝该匹配；
- 协方差下限：位置标准差不低于 0.50 m，速度标准差不低于 0.25 m/s；
- 航迹恢复：连续 3 帧未匹配后，将位置/速度不确定度扩展到 3.0 m 和 1.5 m/s，重新开放后续量测搜索范围。

航迹恢复只保留预测状态并扩大不确定度，不读取真实目标身份。该设计避免滤波器在高 SNR 下过度自信，并减轻一次错误关联造成的长期锁定。

### 3.4 与第一张图和 LLM 的接口

关联结果递归更新每条航迹的 `[x, y, vx, vy]`，连续 20 帧后形成 `[batch, history=20, targets=8, state=4]`，随后进入目标交互 GNN 和不确定性感知运动 Token + GPT-2，输出未来 20 帧轨迹。

当前关联熵已保留为接口，但尚未注入 LLM 温度控制；现阶段主要验证历史航迹重建质量对预测性能的影响。

## 4. 完整实验流程

1. 在线生成打乱顺序的未知身份量测；
2. 根据上一帧状态执行运动预测并构造候选二部图；
3. 训练 Edge MLP 和两层 Association GNN；
4. 使用 Stabilized Hungarian-EKF、Edge MLP 和 Association GNN 完成一对一关联；
5. 将关联结果反馈至 Kalman-style 状态更新，递归生成 20 帧历史航迹；
6. 在四个 SNR 下计算 Frame F1、IDF1、IDSW 和位置 RMSE；
7. 固定虚警率扫描 5%–30% 漏检率，固定漏检率扫描每帧 0.5–5.0 个平均虚警；
8. 鲁棒性测试不针对新条件重新训练模型，用于检验泛化能力；
9. 将重建历史输入 Target GNN 与 Graph+LLM，计算未来 20 帧 ADE/FDE。

所有方法在相同场景、帧和 SNR 下使用相同随机量测、漏检和虚警。

## 5. 训练和测试设置

- 设备：远程 NVIDIA GeForce RTX 4090；随机种子：2026；
- 训练样本：48,000 帧；验证样本：10,000 帧；
- Association GNN：隐藏维度 96、两层二部图消息传递；
- Edge MLP：隐藏维度 96、无图消息传递；
- 最大训练轮数：12，学习率 0.002，batch size 256；
- 训练条件：10% 漏检率、平均每帧 1.5 个虚警；
- 鲁棒性测试：每个条件、每个 SNR 使用 6,000 个单帧样本和 80 个递归场景；
- 下游预测：每个 SNR 使用 120 个场景，共 909 条有效目标轨迹。

## 10. 适用于毕业论文的结论

1. 二部图消息传递能够利用航迹—量测竞争关系，比传统统计匹配保持更好的身份连续性；
2. 在漏检率和虚警率变化时，Association GNN 的性能下降更缓慢；
3. 稳定化后的 Hungarian 已避免明显不公平问题，所提方法在公平基线上仍保持优势；
4. 更好的关联历史能够降低 Graph+LLM 的 ADE 和 FDE，形成从感知关联到轨迹预测的完整论证链条。

## 11. 当前边界

- 当前 40 帧窗口内目标成员固定，尚未评估目标出生、离开和重新出现；
- 当前使用仿真的融合状态量测，而非真实 RD/RA 峰值或检测器输出；
- 当前只运行随机种子 2026，不报告统计显著性；
- 尚未加入 JPDA、MHT 和 HOTA/GOSPA 等完整跟踪基线与指标；
- 关联熵尚未反馈到运动 Token 温度或 LLM 门控。

若第二个点只作为硕士毕业论文的一部分，上述内容可以放入“局限性与未来工作”。
