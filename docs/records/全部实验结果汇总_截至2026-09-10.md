# QGNN＋LLM 全部实验结果汇总（截至 2026-09-10）

## 0. 可比性说明

现有实验分属四套协议，不能横向混算：

1. 早期经典 Graph＋LLM：原始完整数据划分；
2. 双层 QGNN 最终测试：1200 个测试场景、5/10/15/20 dB 宏平均；
3. 后续接口研究：991 个完整开发场景，只用于模型选择和机制验证；
4. 4 秒长时域与量测关联图：数据集合或任务不同，只能在各自协议内比较。

所有量子结果均来自 PennyLane 0.31.1 `default.qubit` 解析态矢量模拟器（`shots=None`），固定训练种子 2026。

## 2. 双层 QGNN 最终测试结果

## 9. 其他已完成的负结果与排障结论

- 量子输出直接扩展到高维 value：量子 0.677705/1.311409，经典 0.675193/1.303526，量子更差。
- basis-mixing 从零训练：经典已退化至 0.699142/1.362656；量子无改善，停止。
- basis-mixing 热启动：量子前 3 轮未超过 epoch 0。
- LLM 阶段解冻 QGNN：第 5 轮后退化；冻结图骨干后达到 0.671203/1.299919。
- 高复杂度定向微调：测试 0.645751/1.254935，未超过主测试检查点 0.644688/1.253012。
- 高机动物理规则：开发集优势未在测试集复现。
- 两跳稀疏交互探索：独立开发确认块曾见约 1.05% ADE/0.92% FDE 量子改善，但无 LLM、无最终测试，只能作为线索。
- 自由量子关系 token：约 0.015% 增益，注意力接近均匀。
- 时间碰撞风险注意力：注意力更集中，但误差收益没有扩大。
- 原始量子测量直接作为 LLM token：6 轮未超过 epoch 0。
- 边级未来交互解码：直接坐标版第 3 轮差约 0.097%/0.051%；相对位置监督版第 2 轮差约 0.008%/0.004%；高交互专家版第 1 轮差约 0.004%/0.002%，均停止并保留主检查点。

## 10. 当前最终判断

当前冻结主方案是有效关系三阶段 QGNN＋LLM，开发集 0.669766/1.296094。它稳定优于 Plain GNN 和纯 QGNN；LLM 的增量价值成立，最清楚的 QGNN→LLM 接口是图 token。总体上匹配经典 GNN＋LLM 仍有更低 ADE，量子优势只在高闭合、高机动和最高复杂度子组表现为约 0.4%–1.4% 的单种子趋势，尚不能声称普适或统计显著的量子优势。
