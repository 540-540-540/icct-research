# LLM 组件消融实验结果（2026-09-10）

## 1. 实验目的

本轮只回答一个问题：未来 token 分支中的三类输入——运动 token、QGNN 图 token、可学习未来查询 token——各自是否真的改善最终轨迹预测。

为保证公平，三组模型均使用 seed 2026、同一冻结 QGNN、同一 QGNN+LLM 起始 checkpoint、4 轮预热加 12 轮联合训练，并在同一个固定 256 样本验证子集上选择最佳 epoch，最后只评估完整开发集，不触碰测试集。完整模型直接引用已经保存的 future-token QGNN+LLM 结果。

这里删除的是**未来 token 分支**中的相应输入。原有坐标修正分支保持不变，因此所有模型在 epoch 0 都与同一个 QGNN+LLM 起点完全一致。这种设计能够单独测量新未来分支中每个组件的增量价值。

## 2. 完整开发集结果

| 模型 | 最佳 epoch | ADE / m ↓ | FDE / m ↓ | 完整模型相对该模型的 ADE 改善 | FDE 改善 |
|---|---:|---:|---:|---:|---:|
| 完整 future-token QGNN+LLM | 14 | **0.670060** | 1.296719 | — | — |
| 去掉未来分支运动 token | 11 | 0.670210 | 1.297370 | +0.0225% | +0.0502% |
| 去掉未来分支 QGNN 图 token | 16 | 0.671172 | 1.299832 | **+0.1658%** | **+0.2395%** |
| 去掉可学习未来查询 token | 13 | 0.670081 | **1.296586** | +0.0032% | −0.0102% |

作为参照，未来分支加入前的保留 QGNN+LLM 模型为 ADE 0.671203、FDE 1.299919。完整 future-token 分支相对它改善 0.1704% ADE 和 0.2462% FDE；去掉图 token 后为 0.671172/1.299832，几乎完全退回这一旧起点。因此，新未来分支的增益基本来自 **QGNN 图表示进入 LLM**，而不是仅靠新增参数或训练轮次。

## 3. 配对时间块 bootstrap

使用 10,000 次配对时间块 bootstrap，共 12 个时间块。正值表示完整模型优于删减模型。

| 消融 | ADE 改善及 95% CI | 完整模型更优概率 | FDE 改善及 95% CI | 完整模型更优概率 |
|---|---:|---:|---:|---:|
| 去运动 token | +0.0225% [−0.0255%, 0.0786%] | 81.38% | +0.0502% [−0.0205%, 0.1308%] | 91.48% |
| 去 QGNN 图 token | **+0.1658% [0.0602%, 0.2973%]** | **99.95%** | **+0.2395% [0.0929%, 0.4258%]** | **99.97%** |
| 去未来查询 token | +0.0032% [−0.0238%, 0.0306%] | 56.78% | −0.0102% [−0.0446%, 0.0262%] | 27.92% |

这些区间只衡量当前单一训练种子下的场景/时间块变化，不能替代多训练种子不确定性。

## 4. 可用于当前论文叙事的结论

1. **QGNN 与 LLM 的有效衔接点已经被定位到图 token。** 去掉未来分支中的 QGNN 图 token 后，ADE/FDE 均稳定退化，配对区间不跨 0，而且模型几乎回到加入未来分支前的结果。
2. **运动 token 的正贡献很小，当前证据不足。** 点估计方向有利，但两个 95% 区间均跨 0，不能写成已经得到统计支持的关键模块。
3. **可学习未来查询 token 没有证明必要。** 去掉它后 ADE 基本不变，FDE 还略好；两项差异均落在波动范围内。当前更合理的简化方案是保留因果未来位置及类型编码，去掉额外的可学习 query 内容。
4. **本轮支持“图条件化的未来推理”，不支持“三种 token 都不可缺少”。** 最稳妥的结构故事是：QGNN先提取交互关系，图 token 将这种关系送入 LLM，LLM在因果未来序列中把关系信息转成逐时刻轨迹修正。

## 5. 对主方案的直接建议

下一版主方案应以“无可学习未来 query”作为更简洁候选，并把图 token 保留为核心接口。运动 token 暂时保留，因为其点估计没有伤害性能，但论文中只作为历史运动上下文描述，不把它列为已被显著验证的核心贡献。

本轮结果适合放入组件消融表，但在正式论文定稿前，应在最终 effective-relation 架构上复现同样的“去图 token”和“去未来 query”两项，并至少补充多个训练种子。
