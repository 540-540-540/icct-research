# 第二研究点代码实现与阶段实验结果

## 1. 当前结论

当前代码完成了《第二研究点_不确定性感知双图多目标ISAC方案.md》中建议优先验证的 Level-0 路线：

1. 从原始 Lankershim NGSIM CSV 中保留共同 `Global_Time`，构造同一时刻的多目标场景；
2. 使用共享但逐目标独立的 GRU 作为公平基线；
3. 加入目标交互图，利用相对位置、相对速度、距离、接近速度和 TTC 建模目标间影响；
4. 图网络通过性能闸门后，再接入不确定性引导的运动 Token、本地 GPT-2 和 LoRA；
5. Graph+LLM 的坐标修正层采用零初始化，因此训练开始时严格退化为已经验证的 GNN，最终检查点只按验证集 ADE/FDE 选择。

本阶段在远程 NVIDIA GeForce RTX 4090 上训练和测试。固定随机种子为 2026，使用 6000/1200/1200 个训练/验证/测试场景，三个集合按原始时间轴 70%/15%/15% 切分，不随机打散时间段，避免同一时间邻近窗口跨集合泄漏。

## 2. 正式测试结果

单位为米；数值越低越好。所有模型使用相同测试集和相同确定性观测噪声（位置标准差 0.35 m、速度标准差 0.20 m/s）。

| 模型 | ADE | FDE | 交互目标 ADE | 交互目标 FDE | 额外碰撞率 |
|---|---:|---:|---:|---:|---:|
| 匀速模型 | 1.0563 | 2.0387 | 1.0246 | 1.9657 | 3.9042% |
| 独立 GRU | 0.7001 | 1.4685 | 0.6731 | 1.4103 | 0.5875% |
| 目标交互 GNN | 0.6202 | 1.2529 | 0.5956 | 1.2012 | 0.2167% |
| 目标交互 GNN + 不确定性运动 Token + GPT-2/LoRA | **0.5925** | **1.1956** | **0.5673** | **1.1439** | 0.2792% |

阶段性能闸门：

- GNN 相对独立 GRU：ADE 提升 11.42%，FDE 提升 14.68%，交互目标 ADE 提升 11.52%；
- Graph+LLM 相对 GNN：ADE 再提升 4.47%，FDE 再提升 4.57%，交互目标 ADE 再提升 4.74%；
- 最终 Graph+LLM 相对独立 GRU：ADE 约提升 15.38%，FDE 约提升 18.58%；
- Graph+LLM 的额外碰撞率略高于纯 GNN，但仍明显低于独立 GRU。后续可加入显式碰撞/可行驶区域损失优化该项。

## 3. 新增代码文件

- `multitarget_scene_dataset.py`：从原始 CSV 生成时间同步、旋转平移到锚目标坐标系的多目标场景缓存；
- `target_interaction_graph.py`：独立 GRU、公平共享骨干、稠密边特征图注意力和目标交互 GNN；
- `evaluate_multitarget.py`：ADE、FDE、交互子集指标、预测碰撞率和额外碰撞率；
- `run_multitarget_experiment.py`：缓存构建、独立基线训练、GNN 热启动、验证集早停和第一阶段性能闸门；
- `MultiTargetTimeLLM.py`：冻结已验证 GNN，进行不确定性软运动 Token 化，并将图上下文注入本地 GPT-2；采用 LoRA 适配和零初始化坐标残差；
- `run_multitarget_graph_llm.py`：Graph+LLM 训练、未来运动 Token 辅助监督、第二阶段性能闸门和结果保存。

## 5. 必须保留的学术边界

当前结果使用原始数据中的真值 `Vehicle_ID`，要求目标在历史和预测窗口内连续出现。因此，它已经是多目标交互轨迹预测，但还不能表述为已经完成“从回波到航迹”的完整多目标跟踪，也不能声称已经解决未知数据关联。

论文中当前可使用的准确表述是：

> 在保留真值轨迹 ID 的多目标场景中，验证目标交互图与图条件不确定性运动 Token 对多目标轨迹预测的有效性。

下一阶段应补齐第二张图：生成多 BS、多目标回波/量测，加入漏检、虚警和遮挡，构造“量测—航迹关联图”，再把关联后验和状态协方差送入本代码的目标交互图与 LLM。届时需要增加 HOTA、IDF1、MOTA、ID Switch、漏检率和虚警率，才能把工作完整表述为多目标感知与轨迹跟踪。

## 6. 后续论文实验建议

正式投稿前至少补充：

1. 3--5 个随机种子的均值和标准差，并做配对显著性检验；
2. 去除图、去除不确定性温度、硬 Token、冻结 GPT-2、无 LoRA、无未来 Token 辅助损失等消融；
3. 按目标密度、最近邻距离、交叉口/非交叉口、遮挡强度和 SNR 分组；
4. 参数量、可训练参数量、训练时间、单场景推理延迟和显存占用；
5. 显式碰撞损失或道路约束，降低 Graph+LLM 相对纯 GNN 略高的碰撞率；
6. 第二张量测—航迹图以及完整多目标跟踪指标。
