# QGNN 与 LLM 有效衔接实验结果（截至 2026-09-09）

## 1. 本轮目的与结论

本轮不改变论文的两项核心模块：物理对齐双层 QGNN 与 GPT-2＋LoRA。目标是避免把两者做成简单的“QGNN 预测＋LLM 残差”，寻找只有二者共同参与才成立的接口。

结论分为三层：

1. **未来词 LLM 路径有效，但总体增益仍小。**让 20 个未来查询真正进入 GPT-2，并将运动词概率可微解码为轨迹后，量子模型完整开发集由 0.671203/1.299919 改善到 **0.670060/1.296719**，ADE/FDE 分别改善 **0.170%/0.246%**。
2. **QGNN 注意力路由 LLM 的有效位置在高交互场景。**两层 QGNN 注意力直接聚合不同目标的 LLM 未来隐藏状态后，高复杂度组相对未路由 QGNN＋LLM 改善 **0.052% ADE/0.036% FDE**，但低、中复杂度组退化，因此总体 ADE 未改善。
3. **“LLM 有价值”已有稳定证据，“量子优于匹配经典”仍只有趋势。**高复杂度组中，QGNN 路由＋LLM 相对纯 QGNN 的 ADE 改善 **0.625%**，bootstrap 95% CI 为 **[0.359%, 0.888%]**；相对同结构经典路由＋LLM，FDE 改善 **0.645%**，但 95% CI 为 **[-0.758%, 1.995%]**，不能表述为显著量子优势。

因此，当前应保留原最终测试模型作为正式基线，同时把“高交互场景中的量子关系路由＋LLM 时序推理”作为下一阶段主路线。不能用本轮开发结果覆盖原测试结论，也不能声称总体量子优势已经成立。

## 3. 路线一：未来运动词真正进入 LLM

### 3.1 机制

旧模型先用 GPT-2 压缩历史，再在 GPT-2 外部加 20 个未来查询；未来 token 没有进入 Transformer，token 概率也不直接决定坐标。

新版采用：

1. 历史运动 token 与图 token 进入 GPT-2；
2. 20 个未来查询也作为因果序列进入独立的 GPT-2＋LoRA 未来分支；
3. 每一步输出 441 类局部运动词概率；
4. 概率经可微软解码得到逐步坐标；
5. 零初始化融合门从原最优模型精确起步，学习何时采用运动词轨迹。

冒烟检查中，新模型 epoch 0 与原模型的最大坐标差为 **0.0 m**。未来查询、token 头、未来 LoRA、逐步残差和融合强度均收到非零梯度。

### 3.2 完整开发集结果

| 模型 | ADE (m) | FDE (m) | 相对各自旧 LLM 的改善 |
|---|---:|---:|---:|
| 旧 QGNN＋LLM | 0.671203 | 1.299919 | — |
| **未来词 QGNN＋LLM** | **0.670060** | **1.296719** | **0.170% / 0.246%** |
| 旧经典 GNN＋LLM | 0.668887 | 1.300758 | — |
| **未来词经典 GNN＋LLM** | **0.668063** | **1.297259** | **0.123% / 0.269%** |

量子侧 ADE 增益略大，经典侧 FDE 增益略大。这说明未来词接口是有效的通用 LLM 改进，但尚不能证明它与量子表示存在独特匹配。

相对纯 QGNN 0.675118/1.303763，未来词 QGNN＋LLM 的 ADE/FDE 改善为 **0.749%/0.540%**。

## 4. 路线二：QGNN 注意力直接路由 LLM 未来状态

### 4.1 核心衔接

双层 QGNN 分别产生物理关系注意力与上下文关系注意力。对未来第 \(t\) 步，使用每层量子图注意力聚合其他目标的 LLM 隐状态：

\[
c_{i,t}^{(l)}=\sum_{j\ne i}A_{ij}^{(l)}h_{j,t}^{\mathrm{LLM}}.
\]

坐标修正头只读取本目标状态与两个量子路由邻居状态之间的差异和乘性耦合。它没有独立的 QGNN-only 或 LLM-only 输入旁路。因此：

- QGNN 决定“哪个目标的未来状态应传给当前目标”；
- LLM 提供“每个目标在不同未来时刻的时序表示”；
- 融合头解释“邻居未来与自身未来的冲突会如何改变坐标”。

输出层零初始化，epoch 0 与未来词 QGNN＋LLM 完全一致。

### 4.2 总体开发集

| 模型 | ADE (m) | FDE (m) |
|---|---:|---:|
| 未来词 QGNN＋LLM（路由前） | **0.670060** | 1.296719 |
| QGNN 注意力路由＋LLM | 0.670227 | **1.296676** |
| 未来词经典 GNN＋LLM（路由前） | **0.668063** | 1.297259 |
| 经典注意力路由＋LLM | 0.668409 | **1.296738** |

总体上，两种路由都只轻微改善 FDE，并使 ADE 退化。QGNN 路由与经典路由的总体 FDE 几乎相同，不能作为总体优势证据。

### 4.3 无结果泄漏的复杂度分层

复杂度分层复用既有定义，仅由目标数、20 m 内近邻对数、5 s 冲突对数、闭合速度和机动强度构成，不使用预测误差。完整开发集分为低 331 场景、中 330 场景、高 330 场景。

| 复杂度 | QGNN 路由相对路由前 ADE | QGNN 路由相对路由前 FDE |
|---|---:|---:|
| 低 | -0.135% | -0.032% |
| 中 | -0.048% | -0.015% |
| **高** | **+0.052%** | **+0.036%** |

高复杂度组的关键比较：

| 比较 | ADE 改善 | FDE 改善 |
|---|---:|---:|
| QGNN 路由＋LLM vs 纯 QGNN | **+0.625%** | **+0.208%** |
| QGNN 路由＋LLM vs 匹配经典路由＋LLM | -0.002% | **+0.645%** |

| 比较 | 指标 | 点估计 | 95% CI | 改善概率 |
|---|---|---:|---:|---:|
| QGNN 路由＋LLM vs 纯 QGNN | ADE | +0.625% | **[+0.359%, +0.888%]** | 1.000 |

可以表述：高交互场景中，LLM 对 QGNN 的 ADE 改善稳定；量子路由在 FDE 上相对匹配经典路由呈正向趋势。不能表述：QGNN＋LLM 已显著优于经典 GNN＋LLM。

## 5. 未保留为主方案的诊断尝试

1. **自由量子关系 token。**两层电路的 12 维边测量值、\(1-z^2\) 不确定性和物理边特征组成关系 token，未来查询自由注意这些 token。注意力接近均匀，2 轮增益约 0.015%，停止。
2. **时间碰撞风险注意力。**用闭合速度、距离和预计碰撞时间引导未来查询，注意力熵由约 2.3 降至约 1.0，但验证收益没有扩大，停止。
3. **关系 token 与 LLM 隐状态直接融合。**6 轮均未超过 epoch 0，最终自动选择 epoch 0。说明原始量子测量值对 LLM 是冗余接口，QGNN 已经把它们压缩成了更有用的图注意力。

这些失败结果没有替换任何正式检查点，其作用是排除“直接把量子数值当普通 token”这一接口。

## 6. 下一步主路线

主方案继续保持双层 QGNN＋LLM，但研究任务应明确聚焦高交互场景：

1. 在方法与实验协议中预先定义高交互条件，不用预测误差挑样本；
2. 训练时按冲突对、闭合速度和机动强度平衡采样，减少低复杂度场景对交互梯度的稀释；
3. 保留 QGNN 注意力路由 LLM 隐状态这一乘性接口；
4. 同时报告全体场景与预注册高交互场景，主张限定为后者；
5. 除 ADE/FDE 外加入碰撞率、最小目标间距误差和冲突目标 FDE，使评价指标与量子关系建模的职责一致；
6. 最终仍需至少补 3 个训练种子，当前单种子 bootstrap 只衡量场景采样不确定性。

## 8. 2026-09-09 新增：有效关系三阶段信任接口

### 8.1 为什么修改接口

QGNN 每条边的真实消息为

\[
m_{ij}=\alpha_{ij}g_{ij}v_{ij},
\]

此前的注意力路由只使用了 \(\alpha_{ij}\)，遗漏了量子电路产生的消息门控 \(g_{ij}\)。新版使用有效关系强度 \(\alpha_{ij}g_{ij}\) 聚合邻居的 LLM 未来隐状态，并预测前段、中段、后段三个 LLM 信任倍率。三个倍率从 1 初始化，因此 epoch 0 与原未来词 QGNN＋LLM 的最大差仅为 **7.45e-9 m**。

功能分工为：

- QGNN 判断谁与谁发生作用，以及一条关系允许多少信息通过；
- LLM 表示每个目标从历史到未来的时序演化；
- 三阶段信任门决定 LLM 修正在预测早期、中期和末期分别使用多少。

训练后倍率呈随时间增大的趋势，典型均值约为 **1.04 / 1.07 / 1.09**，说明 LLM 修正对中长期预测更有价值。

### 8.2 开发集与独立高交互确认集

| 数据范围 | 原 QGNN＋LLM ADE/FDE | 新接口 ADE/FDE | 改善 |
|---|---:|---:|---:|
| 完整开发集 991 场景 | 0.670060 / 1.296719 | **0.669766 / 1.296094** | **0.044% / 0.048%** |
| 与选择集不重叠的高交互确认集 | 0.831089 / 1.634382 | **0.830900 / 1.633979** | **0.023% / 0.025%** |

完整开发集逐场景配对 bootstrap：新接口相对原 QGNN＋LLM 的 ADE 改善 95% CI 为 **[0.032%, 0.056%]**，FDE 为 **[0.033%, 0.063%]**，改善概率均为 1.000。该区间只反映场景采样，不替代多训练种子。

消融结果表明，关闭跨目标路由后独立确认集退化到 0.831096/1.634331；但 uniform 路由为 0.830886/1.633941，略好于 learned \(\alpha g\) 的 0.830900/1.633979。因而跨目标 QGNN→LLM 接口有效，但当前数据尚未证明 learned 量子权重优于均匀邻居关系。

### 8.3 完整贡献链

| 模型（完整开发集） | ADE (m) | FDE (m) |
|---|---:|---:|
| Plain GNN | 0.685107 | 1.328154 |
| 纯 QGNN | 0.675118 | 1.303763 |
| 原未来词 QGNN＋LLM | 0.670060 | 1.296719 |
| **有效关系三阶段 QGNN＋LLM** | **0.669766** | **1.296094** |
| 匹配经典图＋LLM | 0.667706 | 1.296894 |

最终方案相对 Plain GNN 改善 **2.239% ADE / 2.414% FDE**；相对纯 QGNN 改善 **0.793% / 0.588%**，两项配对 bootstrap 95% CI 均完全为正。相对匹配经典图＋LLM，总体 ADE 差 0.309%，FDE 好 0.062%，总体量子优势不显著。

### 8.4 结果无关的困难场景分层

分层只使用输入历史中的目标数、20 m 近邻对、5 s 预计冲突对、闭合强度和机动强度，不使用任何模型误差。

| 分层 | 量子相对匹配经典 ADE | 量子相对匹配经典 FDE |
|---|---:|---:|
| 全部 991 场景 | -0.309% | +0.062% |
| 综合复杂度最高 20%（199） | -0.006% | **+0.787%** |
| 综合复杂度最高 10%（100） | **+0.682%** | **+1.382%** |
| 闭合强度最高 10%（100） | **+1.106%** | **+1.397%** |
| 机动强度最高 10%（100） | **+0.415%** | **+1.356%** |

综合复杂度最高 10% 中，最终方案相对纯 QGNN 改善 **0.729% ADE / 0.601% FDE**；ADE 95% CI 为 **[0.312%, 1.164%]**，FDE 为 **[0.069%, 1.122%]**。这证明 LLM 对困难场景中的 QGNN 有稳定增益。

量子相对经典在最高 10% 综合复杂度中的点估计为 0.682% ADE 和 1.382% FDE，但 95% CI 仍跨 0（ADE [-1.086%, 2.471%]；FDE [-0.754%, 3.582%]）。因此论文可表述为“量子优势随交互复杂度增强的单种子趋势”，不能表述为统计显著优势。

### 8.5 当前最稳妥的论文论点

1. QGNN＋LLM 不是简单串联：量子图的有效边影响 \(\alpha g\) 直接控制邻居 LLM 未来状态如何进入当前目标，并进一步控制早、中、后段的修正幅度。
2. LLM 的独立价值已经得到稳定证据：最终模型相对纯 QGNN 在全体与最高 10% 综合复杂度场景均改善，且相应配对场景 bootstrap 为正。
3. QGNN 的价值集中在复杂交互：相对匹配经典模型的总体优势有限，但在综合复杂度、闭合强度和机动强度最高 10% 中，ADE/FDE 点估计同时改善约 0.4%–1.4%。
4. 证据边界必须保留：困难子组约 100 个场景，量子对经典的置信区间仍跨 0；正式论文需补多训练种子或扩大高交互评估集。

新增关键代码：`interaction_trust_model.py`、`run_effective_segment_trust.py`、`evaluate_effective_complexity.py`、`analyze_contribution_chain.py`。新增结果：`effective_segment_qgnn_llm_seed2026_v1` 与 `effective_segment_classical_llm_seed2026_v1`。本轮仍未重新使用测试集。

## 9. 2026-09-10 新增：边级未来交互解码器排障与最终冻结

### 9.1 验证目标

为进一步强化 QGNN 与 LLM 的直接耦合，本轮实现了边级未来交互解码器：

- QGNN 提供每条目标边的 12 维电路测量潜变量和真实消息强度 \(\alpha_{ij}g_{ij}\)；
- LLM 提供每个目标、每个未来时刻的隐藏状态；
- 解码器在目标对 \((i,j)\) 与未来时刻 \(t\) 上联合读取两者，产生邻居影响；
- 输出层零初始化，三版模型的 epoch 0 均与冻结的未来词 QGNN＋LLM **完全一致（最大差 0.0 m）**；
- 冻结原 QGNN 与 LLM，只训练新接口，避免把旧模型退化误判为衔接收益。

### 9.2 三个依次验证的假设

| 版本 | 关键假设 | 观察结果 | 决策 |
|---|---|---|---|
| 直接坐标边解码 | 每条量子边与 LLM 未来状态可直接生成接收目标坐标修正 | 第 3 轮选择集 ADE/FDE 比源模型差约 **0.097%/0.051%** | 停止；边贡献缺少直接标签，分解有歧义 |
| 未来相对位置监督 | 每条边先拟合“真实未来相对位置－源模型相对位置”，再解析转换为坐标修正 | 第 2 轮仍差约 **0.008%/0.004%**，最佳为 epoch 0 | 停止；边几何损失下降不等于绝对轨迹改善 |
| 高交互风险专家 | 仅在历史中距离近、相互接近的目标上启用边解码，其余严格回退 | 第 1 轮仍差约 **0.004%/0.002%**，最佳为 epoch 0 | 停止；当前冻结模型的可学习剩余量不足 |

所有停止均依据预先固定的开发选择集；没有使用测试集，也没有以偶然单项波动替换主检查点。三组失败目录均保留 `protocol.json`、`training.jsonl`、`progress.json` 与 `stopped.json` 作为排障证据。

### 9.3 底层结论

新接口在数学上比三阶段信任门更强，但仍未带来更大泛化收益，说明当前瓶颈不再是“QGNN 与 LLM 是否直接相连”，而是数据和任务中的**剩余交互信息量**：

1. 当前轨迹的大部分误差可由自身历史运动决定，跨目标关系只解释很小的残差；
2. 原双层图网络已经在进入 LLM 前聚合了邻居信息，新边解码器再次读取相同关系，新增条件信息有限；
3. 未来真实标签只提供每个目标的绝对轨迹，并不提供“邻居 \(j\) 对目标 \(i\) 的因果位移”，强行学习边贡献容易产生不可辨识分解；
4. 量子与匹配经典核心都只有低维关系输出，在当前样本规模下，经典核心足以拟合主要模式，量子表达能力没有转化为总体误差优势；
5. 修正量长期停留在毫米级，而基准 ADE 约为 0.67 m，说明头部调参的理论收益空间已经很小。

### 9.4 最终冻结结果与论文使用边界

截至 2026-09-10，仍冻结第 8 节的**有效关系三阶段 QGNN＋LLM**为当前最佳且可复现主方案：

- 完整开发集：**0.669766 m ADE / 1.296094 m FDE**；
- 相对 Plain GNN：**改善 2.239% / 2.414%**；
- 相对纯 QGNN：**改善 0.793% / 0.588%**；
- 综合复杂度最高 10% 中，相对匹配经典图＋LLM：点估计改善 **0.682% / 1.382%**；
- 闭合强度最高 10% 中，相对匹配经典图＋LLM：点估计改善 **1.106% / 1.397%**。

可以把前两项作为“完整模型与各组成基线”的主结果，把后两项作为“量子关系模块在强交互场景更有价值”的分层结果。不能把量子对经典的最高 10% 点估计写成统计显著优势，因为当前单种子配对置信区间仍跨 0。

若论文必须获得更明显且稳健的量子相对经典提升，下一项实验不应继续增加融合头，而应扩大或构造预先定义的高交互数据：提高同时目标数、近距离闭合与冲突事件比例，并增加碰撞率、最小间距误差、冲突目标 FDE 等关系敏感指标。该改变保持“双层 QGNN＋LLM”主路线不变，只让评价任务真正包含足够的关系信息。

## 10. 2026-09-10 新增：QGNN 条件化三阶段意图 Token 规划器

### 10.1 方法与验证协议

为使 LLM 承担明确的高层未来推理职责，新版将 20 步未来划分为早、中、后三段，并由未来真值自动产生三组训练标签：

- 纵向意图：减速、稳定、加速；
- 横向意图：向右、直行、向左；
- 交互演化：接近、稳定、远离。

QGNN 的两层有效关系 \(\alpha g\) 先路由每个目标逐时刻的 LLM 隐状态，再预测上述意图 Token。意图概率与路由后的 LLM 时序状态共同生成分阶段轨迹候选。前 2 轮只学习语义意图与候选轨迹，后 8 轮打开三个阶段的融合强度。融合强度从 0 初始化，因此 epoch 0 与冻结源模型的最大坐标差为 **0.0 m**。

训练集标签没有坍缩：每种任务、每个阶段的三个类别均包含数千样本。第 10 轮量子模型的训练意图准确率稳定在约 60%–65% 范围，明显高于三分类随机水平。所有模型仍只用固定开发集选型，没有重新使用测试集。

### 10.2 量子与严格同构经典结果

| 模型（完整开发集） | ADE (m) | FDE (m) | 相对各自未来词源模型 |
|---|---:|---:|---:|
| 未来词 QGNN＋LLM 源模型 | 0.670060 | 1.296719 | — |
| 意图 Token QGNN＋LLM | **0.670030** | **1.296687** | **+0.0044% / +0.0024%** |
| 未来词经典 GNN＋LLM 源模型 | 0.668063 | 1.297259 | — |
| 意图 Token 经典 GNN＋LLM | **0.668021** | **1.297213** | **+0.0062% / +0.0035%** |

意图 Token QGNN＋LLM 相对纯 QGNN 的最终改善约为 **0.754% ADE / 0.543% FDE**，没有达到预设的 1% 目标，也低于第 8 节最终冻结方案相对纯 QGNN 的 0.793%/0.588%。因此该版本不替换最终主检查点。

量子意图模型相对同构经典意图模型的 ADE 差约 **0.301%**，FDE 好约 **0.041%**，与此前总体量子/经典格局一致，不能证明总体量子优势。

### 10.3 关系与意图机制诊断

量子模型完整开发集消融：

| 设置 | ADE (m) | FDE (m) |
|---|---:|---:|
| learned QGNN relation | **0.670030** | **1.296687** |
| uniform relation | 0.670036 | 1.296690 |
| relation off | 0.670059 | 1.296728 |

learned 关系优于 uniform 和 relation-off，方向符合设计，但相对 relation-off 只有约 **0.0043% ADE / 0.0031% FDE**，实际贡献仍非常小。

进一步进行了仅用于定位瓶颈的 oracle 实验：在评估时把模型预测的意图概率替换为由真实未来轨迹生成的正确意图标签。该设置使用未来信息，**不能作为论文性能结果**。量子 oracle 为 0.670024/1.296676，相对正常预测只改善约 **0.0009%/0.0009%**。即使意图完全正确也几乎不能继续降低坐标误差，说明瓶颈并非 60%–65% 的意图分类准确率，而是当前三类粗粒度意图没有提供源轨迹之外足够的新坐标信息。

### 10.4 本轮结论

本轮证明了 QGNN 关系可以帮助 LLM 学习可解释的分阶段未来意图，且关闭关系后结果按预期退化；但语义可预测性没有转化为足够的 ADE/FDE 收益。结合 oracle 上界，继续调整意图分类头、损失权重或训练轮数不太可能达到 1%。

当前最终主方案仍为第 8 节的有效关系三阶段 QGNN＋LLM。下一阶段若坚持至少 1% 的 LLM 增益，需要改变 LLM 获得的信息，而不是继续改变融合形式：应加入车道拓扑、车辆类别、信号灯、地图约束或更长历史等 QGNN 当前节点状态中没有的信息；若数据集无法提供这些信息，则应扩大高交互数据并把关系敏感指标作为主要任务。否则，只凭相同的位置/速度序列，LLM 与 QGNN 接收到的信息高度重复，1% 额外提升缺乏数据基础。

## 11. 2026-09-10 新增：4 秒长预测范围验证

### 11.1 数据与可比性

原缓存为 20 步历史＋20 步未来，采样间隔 0.1 s，即 2 秒预测。新缓存从相同的原始 Lankershim CSV 中按原场景起点和目标 ID 扩展为 20 步历史＋40 步未来，即 4 秒预测。只有无法提供完整 4 秒未来的场景被剔除。

- 长时域缓存：`data/multitarget_lankershim_h20_p40_matched_v1.npz`；
- 保留原训练场景 5,133 个，其中 circuit-train 3,450、circuit-dev 861；
- 新旧缓存前 40 帧逐值复核最大差为 **0.0 m**；
- 40 步 QGNN 初始化后的前 20 步与冻结 20 步 QGNN 最大差为 **1.91e-6 m**；
- 仍为单种子，固定 256 场景开发选择集，没有读取测试指标。

### 11.2 训练协议

先从原 20 步 QGNN 的 62 组兼容参数初始化并训练 8 轮 40 步纯 QGNN。随后迁移 85 组兼容 LLM 参数，将 20 个未来查询和坐标头沿时间轴插值到 40 步。LLM 外层采用四阶段零初始化门，epoch 0 与所选 40 步 QGNN 输出完全一致。LLM 训练包含 2 轮候选轨迹预热和 6 轮联合优化。

### 11.3 完整开发集结果

| 4 秒模型 | ADE (m) | FDE (m) |
|---|---:|---:|
| 纯 QGNN | 1.423014 | 3.246469 |
| **QGNN＋LLM** | **1.421641** | **3.243777** |

QGNN＋LLM 相对纯 QGNN 改善约 **0.097% ADE / 0.083% FDE**。四个 SNR 下两项指标方向均为改善，所选第 8 轮四阶段融合强度约为 **0.084 / 0.072 / 0.080 / 0.078**，说明 LLM 确实被采用，但增量依然很小。

### 11.4 结论

将预测范围由 2 秒延长到 4 秒没有扩大 LLM 的相对优势，反而低于 2 秒最终方案相对纯 QGNN 的 0.793%/0.588%。由于长时域场景集合因完整轨迹要求而缩小，两种时域的绝对误差与百分比不应用于直接显著性比较；但在各自严格配对的 QGNN 与 QGNN＋LLM 内部，4 秒增益明显未达到 1%。

这排除了“只需延长时间范围即可体现 LLM”的假设。当前 QGNN 和 LLM 仍只接收相同的历史位置与速度，未来越长只会同时放大二者的不确定性，并不会给 LLM 增加新的条件信息。因此没有继续运行该失败路线的 classical 长时域对照。若要使 LLM 增益达到 1%，后续应优先增加地图/车道、信号灯、车辆类别、轨迹文本语义或关联置信度等 QGNN 当前输入中不存在的信息。
