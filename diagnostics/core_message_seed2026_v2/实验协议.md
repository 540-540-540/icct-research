# 历史条件量子注意力与消息门控 QGNN＋LLM：单种子开发实验（v2）

用户授权：按照新版核心消息替换方案进行实验。唯一训练随机种子 2026。

远端权威目录：`/home/js_cn/sensing/diagnostics/core_message_seed2026_v2`。v1 的纯消息重建实验只作结构诊断，结果与文件保持不变。

## 三组模型

1. plain：原 TargetInteractionGNN 的两层经典图结构，从头训练。
2. classical：保留公共历史编码器、第一图层和轨迹解码器；第二图层采用新的历史条件注意力与消息门控层，非线性核心为 6→6→6 MLP。
3. quantum：与 classical 相同接口和公共初始化，第二图层非线性核心换成 6-qubit、3 层数据重上传的参数化电路，输出 6 个 Z 与 6 个相邻 ZZ 期望。

新决策路径：接收节点历史表示＋发送节点历史表示＋7 维当前物理边特征 → LayerNorm＋263→6 编码＋有界角度 → 量子/经典核心 → 12 维表示 → 唯一的4头注意力分数与消息门控。

消息内容由发送节点的128维线性 value 和7维边特征的128维 edge-value 保留；量子/经典核心决定每条边、每个头如何选择和缩放这些消息。这样避免 v1 用12维观测量直接重建128维消息造成的信息瓶颈，同时量子核心仍处在图聚合的必要决策路径上。

没有并行经典 value/edge-value 消息绕过第二层核心，也没有将该核心作为零标量门的小支路。保留普通图网络的节点恒等残差；第一层仍为经典图层。因此模型准确称为混合 QGNN，不是全量子网络。

classical 核心 84 参数、quantum 核心 54 参数；第二版完整图模型总参数分别为 352178/352148，plain 为 400558。相同接口不代表精确参数匹配，更不代表耗时相同。

## 数据、训练与选模

- 使用既有 circuit 划分：4100 个 circuit-train 场景训练，991 个 circuit-dev 场景作为开发范围。
- 从 circuit-dev 固定均匀选取 256 个场景做每轮选模，最终报告完整 991 个开发场景结果。两者均是开发证据，不宣称独立测试。
- 只读取原 train_states/train_mask；不读取原 val/test 数组。
- 历史20帧、未来20帧、最多8目标。图与 LLM 训练使用已知身份的含噪历史，之后再做未知身份关联的完整链路评估。
- 四档 SNR=5/10/15/20 dB，按批次轮换；各组的数据顺序和量测噪声输入哈希逐轮核对。
- FP32、batch24，图从头训练12轮，AdamW lr=1e-3；含 LLM 训练6轮，图lr=1e-4、非LoRA头lr=3e-4、LoRA lr=7.5e-5；weight decay=2e-4、梯度裁剪3、余弦调度。
- 图阶段使用既有 prediction_loss；含 LLM 阶段使用相同坐标损失＋0.035未来运动Token交叉熵。
- 各阶段从epoch0至固定预算按四档SNR宏平均ADE＋0.35FDE选模，不提前终止、不因某组结果追加轮数。
- GPT-2来自相同本地预训练权重，4层，LoRA rank8；其余LLM头与LoRA公共初始化相同。未加载已经适配旧经典图的LLM微调检查点。
- 图阶段所选检查点进入LLM阶段，全部图参数可训练；GPT-2基础权重冻结并核对哈希，LoRA及任务头训练。
- CoreGraphLLM使用可微图前向，不继承经典父类的no_grad图调用。

## 完整关联链路

固定复用既有经典关联GNN，选择64个固定circuit-dev场景，四档SNR，默认10%漏检、每帧平均1.5虚警。每组模型使用完全相同的递归重建历史，记录输入哈希。只比较目标交互图和含LLM预测器，不训练新关联模块。

关联保持原任务假设：窗口内成员固定、首帧为带噪真实状态初始化。既有关联模型训练范围包含原train，因此该开发子集也不能作为关联模型未见数据。Hungarian硬匹配不参与反向，称完整链路评估，不称全链路可微联合训练。

## 工程与解释边界

- 预验证检查共享初始化、同接口编码/读出初始化、量子图和LLM梯度、目标置换等变性、紧凑检查点恢复、零坐标修正头初始等价。
- 第一次预验证遇到cuDNN不允许eval-mode GRU反向，第二次只在该探针禁用cuDNN，已通过。正式训练正常调用train模式，不改变其后端。
- 12＋6轮属于固定预算单种子开发筛选，不保证收敛。若曲线仍改善，应报告预算限制，不能将负结果扩大为量子方法普遍无效。
- 优势需要分别相对plain与同接口classical判断，不能将新结构改动的收益全部归给量子。
- 使用经典GPU上的解析态矢量模拟，无真实量子硬件、有限shots或速度优势主张。
- 紧凑LLM检查点只保存图、任务头、LoRA等必要状态；基础GPT-2权重依赖原本地gpt2目录，避免重复占用磁盘。
