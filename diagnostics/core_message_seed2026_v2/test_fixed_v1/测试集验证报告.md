# 新版核心消息 QGNN＋LLM：测试集验证报告

状态：已完成。训练种子 2026；冻结开发集所选检查点；测试阶段无训练、调参、校准或模型选择。

测试集包含 1,200 个场景、9,070 条有效目标轨迹，覆盖 5/10/15/20 dB。训练、验证、测试时间窗口不重叠。该测试集属于项目既有测试集，历史实验可能查看过，因此不声称为全新盲测。

## 1. 已知身份含噪历史：完整测试集

四档 SNR 宏平均：

| 模型 | 图 ADE | 图 FDE | Graph＋LLM ADE | Graph＋LLM FDE |
|---|---:|---:|---:|---:|
| plain | 0.733205 | 1.430763 | 0.702575 | 1.369017 |
| classical | 0.719079 | 1.398927 | 0.696802 | 1.358341 |
| **quantum** | **0.716262** | **1.389817** | **0.695043** | **1.347924** |

| plain | 2.3107% | 2.8618% | 1.0722% | 1.5407% |
| classical | 0.3917% | 0.6512% | 0.2525% | 0.7669% |

量子组在四档 SNR 的 ADE/FDE 均低于两个对照，测试方向与开发集一致。

## 2. 配对时间区块检验

按 `test_start_index // 200` 形成 14 个时间区块，进行 10,000 次配对区块自助重采样。区间只反映当前训练检查点和当前观测噪声实现下的测试时间区块波动，不包含训练种子不确定性。

| 比较 | ADE降低及95%区间 | FDE降低及95%区间 | 逐场景胜率 ADE/FDE |
|---|---:|---:|---:|
| quantum graph vs plain graph | 2.3107% [1.6291%, 3.0205%] | 2.8618% [1.9153%, 3.8480%] | 63.25% / 64.25% |
| quantum graph vs classical graph | 0.3917% [-0.0117%, 0.7964%] | 0.6512% [-0.0037%, 1.2689%] | 49.83% / 48.33% |
| quantum LLM vs plain LLM | 1.0722% [0.5941%, 1.5549%] | 1.5407% [0.8864%, 2.2136%] | 56.08% / 57.33% |
| quantum LLM vs classical LLM | 0.2525% [-0.3620%, 0.8460%] | 0.7669% [-0.1755%, 1.6506%] | 46.50% / 47.83% |

因此，当前单种子测试证据能够支持“新版 QGNN＋LLM 优于原始 Graph＋LLM”。相对同接口经典核心，量子组点估计和四档 SNR 方向一致，但区块区间跨零，不能据此宣称已经证明量子特有优势。

## 3. 未知身份关联历史：完整端到端测试

使用同一个冻结经典关联 GNN，在每档 SNR 上先重建一次全部 1,200 个测试场景的历史，再将完全相同的重建历史交给三个 Graph＋LLM 预测器。

| 模型 | ADE | FDE |
|---|---:|---:|
| plain | 0.749657 | 1.427287 |
| classical | 0.747183 | 1.423724 |
| **quantum** | **0.742331** | **1.406744** |

量子组相对 plain 降低 ADE 0.9773%、FDE 1.4393%；相对 classical 降低 ADE 0.6494%、FDE 1.1927%。量子组在四档 SNR 上的 ADE/FDE 也均低于两个对照。

初次调试调用误把 `24` 当成 batch size 传入实际名为 `number_scenes` 的参数，因此只评估了前 24 个场景、190 条轨迹；该结果已经废弃。最终结果明确传入 1,200，并对每档 SNR、每个模型断言有效轨迹数等于 9,070。归档中的 `association_test_full.json` 是唯一正式关联测试结果。

## 4. 结论边界

这次测试支持第二版结构选择：保留高维消息内容，让 6-qubit、3 层量子核心负责注意力和消息门控，能够在主预测和未知身份端到端链路上超过原始 Graph＋LLM。相对同接口经典核心也取得一致的正向点估计，但主预测配对区间仍跨零，因此论文应将其表述为单种子下的量子核心候选优势，而不是统计上已确证的量子优势。

测试结果现已用于最终验证，后续如果继续根据这些数字修改模型，该测试集就会转化为开发反馈，不能再作为同一方案的独立最终测试。
