# QGNN 瓶颈因果验证（截至 2026-09-07）

## 验证设计

本次验证固定第 39 轮 PennyLane QGNN Graph 最佳检查点，不重新训练。开发集被拆成：

- 256 个原检查点选择场景；
- 735 个未参与检查点选择的隔离开发场景。

所有干预都在 5、10、15、20 dB 下评估，没有读取测试集。正百分比表示相对原 QGNN 改善，负百分比表示性能下降。

## 结果

| 干预 | 选择集 ADE | 选择集 FDE | 隔离集 ADE | 隔离集 FDE |
|---|---:|---:|---:|---:|
| score ×2 | +0.1146% | +0.0987% | +0.0846% | +0.0483% |
| gate logit -0.5 | -0.0378% | -0.2528% | +0.0641% | -0.1508% |
| score ×4 | +0.0865% | +0.0390% | -0.0485% | -0.1449% |
| 只保留 ZZ | -0.3496% | -0.3709% | -0.2574% | -0.2096% |
| 只保留 Z | -0.2835% | -0.1428% | -0.2675% | -0.2157% |
| gate logit -1.0 | -0.6698% | -1.1704% | -0.4249% | -0.9495% |
| 强制均匀注意力 | -0.7308% | -0.7457% | -0.8483% | -0.7980% |
| 输入角度 ×0.50 | -1.1552% | -0.9947% | -0.9918% | -0.8124% |
| 输入角度 ×0.75 | -1.2917% | -1.3125% | -1.0393% | -0.9735% |
| 清零全部量子特征 | -1.5256% | -1.4452% | -1.3963% | -1.2586% |
| gate 固定为 1 | -9.4142% | -9.2468% | -8.7383% | -8.4827% |

## 得到确认的结论

### 1. 量子核心确实在贡献性能

清零全部量子特征后，隔离场景 ADE/FDE 分别恶化 1.40%/1.26%。因此当前 QGNN 并不是由经典旁路独立完成预测，量子输出对结果有实际贡献。

### 2. message gate 是当前量子模块的主要有效通道

把 gate 固定为中性值 1 后，隔离场景 ADE/FDE 分别恶化 8.74%/8.48%，是所有干预中影响最大的。当前量子模块主要通过抑制或放大边消息发挥作用。

但简单地将 gate 整体降低 0.5 或 1.0 并没有稳定改善 ADE/FDE。这说明问题不是“量子 gate 平均值太高”这一单一标量偏差，而是需要针对不同边学习更准确的门控。

### 3. attention 有效，但区分度偏弱

强制均匀注意力使隔离场景 ADE/FDE 恶化 0.85%/0.80%，证明量子 attention 已经学到有效的邻居差异。

将 score 放大 2 倍，在选择集和隔离集上都小幅改善；放大 4 倍则在隔离集上回退，说明当前 attention 略偏平滑，适度锐化可能有利，但过度锐化会损害泛化。

对 score ×2 的 735 场景配对时间区块 bootstrap 结果为：

| 指标 | 点估计改善 | 95% 区间 |
|---|---:|---:|
| ADE | 0.0846% | [-0.0822%, 0.2588%] |
| FDE | 0.0483% | [-0.1179%, 0.2468%] |

区间跨越零。因此“attention 温度不足”是可信的结构线索，但当前证据不足以证明它单独能够稳定提高性能，更不足以解释 QGNN 与 MLP 的全部差异。

### 4. Z 和 ZZ 两组测量都在发挥作用

只保留单比特 Z 或只保留相邻 ZZ 都会在隔离集上造成约 0.2%–0.27% 的下降。两类观测量具有互补信息，没有发现其中一组可以直接删除。

### 5. 不能通过推理时缩放解决角度饱和

把已训练模型的角度缩放到 0.5 或 0.75 都使隔离集 ADE/FDE下降约 0.8%–1.0%。这不否定训练期间存在角度饱和，而是说明量子权重和下游读出已经适配原角度分布，推理时改变分布会破坏已学习函数。

要判断角度饱和是否限制最终性能，必须从相同初始化重新训练受控角度范围版本；当前干预不能证明缩小角度范围会改善结果。

## 最终瓶颈判断

当前没有发现一个通过简单后处理即可消除的故障点。证据支持以下层级：

1. **主要功能集中在 message gate。** gate 对结果影响很大，但简单整体偏移无效，说明需要更强的边条件门控表达。
2. **attention 略偏平滑。** score ×2 有一致但很小的改善，统计区间跨零。
3. **量子输出确实有效。** 清零量子特征明显变差，Z 与 ZZ 也都有贡献。
4. **当前量子作用接口形成性能上限。** 量子特征只控制 score/gate，128 维消息 value 仍由经典网络生成；量子模块无法直接编码“应传递什么运动内容”。
5. **MLP 可以学习同类门控函数。** 当前输入是低维经典连续特征，没有观察到量子线路产生 MLP 难以拟合的决策边界，因此充分训练后两者打平。

所以，目前性能提升有限的核心原因更接近“量子表示的下游使用范围过窄、门控与注意力任务本身可被小型 MLP 充分逼近”，而不是量子线路没工作。

## 下一步验证顺序

如继续验证，应只在 Graph 阶段、同一 seed 和开发集上依次训练三个单因素版本：

1. 加入可学习 attention 温度，初始值设为 2，并约束合理范围；
2. 让量子输出额外调制部分 message value，验证量子作用范围是否为真正上限；
3. 从头训练较小角度范围版本，判断角度饱和是否影响优化。

其中第 2 项最能直接检验当前判断；第 1 项成本最低；第 3 项用于验证此前的角度分布观察。量子比特数消融应放在这些接口验证之后。
