# 量子 Value 调制实验报告（截至 2026-09-07）

## 1. 实验目的

上一轮因果验证发现，量子核心虽然有效，但只负责邻居注意力分数和每个注意力头的标量门控，消息的 value 内容仍完全来自经典网络。本实验检验：让核心输出进一步直接控制每条边、每个消息通道的 value，能否释放 QGNN 的优势。

## 2. 严格配对设计

- 训练种子：2026（单种子快速排查）。
- 两个新分支：`classical_value` 与 `quantum_value`。
- 新通道：`channel = 2 sigmoid(W_value z)`，随后 `message = channel × base_message`。
- `W_value` 从全零初始化，因此第 0 轮 `channel=1`，两个新模型与各自旧模型的初始预测逐元素完全一致，最大差为 0。
- 两个分支共享的数据顺序、噪声、训练/选择/dev 划分、优化器、学习率、最多 40 轮和早停规则完全相同。
- 参数量：经典 353,714；量子 353,684，仅差 30 个参数，且经典对照参数略多。
- PennyLane 后端：`default.qubit` 解析态矢量、反向传播求导。
- 本实验没有训练 LLM，也没有读取测试集。

## 3. 完整 dev 结果（991 个场景，四个 SNR 宏平均）

| 模型 | 选择轮次 | ADE (m) | FDE (m) |
|---|---:|---:|---:|
| 旧 classical | 39 | 0.676196 | 1.308717 |
| **classical_value** | **40** | **0.675193** | **1.303526** |
| 旧 quantum | 39 | 0.676327 | 1.309241 |
| **quantum_value** | **39** | **0.677705** | **1.311409** |

相对变化：

- `classical_value` 相对旧 classical：ADE 改善 0.148%，FDE 改善 0.397%。
- `quantum_value` 相对旧 quantum：ADE 恶化 0.204%，FDE 恶化 0.166%。
- `quantum_value` 相对 `classical_value`：ADE 落后 0.372%，FDE 落后 0.605%。

## 4. 配对区块 bootstrap

使用 12 个时间区块、10,000 次重采样。正数表示候选模型更好。区间只反映当前训练种子下的场景/时间区块变化，不包含训练种子不确定性。

| 比较 | ADE 改善及 95% CI | FDE 改善及 95% CI |
|---|---:|---:|
| quantum_value vs classical_value | -0.372% [-1.023%, 0.114%] | -0.605% [-1.457%, 0.087%] |
| quantum_value vs 旧 quantum | -0.204% [-1.005%, 0.665%] | -0.166% [-1.057%, 0.844%] |
| classical_value vs 旧 classical | 0.148% [-0.366%, 0.662%] | 0.397% [-0.387%, 1.191%] |

所有区间均跨 0。单种子下不能把这些小差异解释为稳定优势，但结果方向清楚地表明：加入相同 value 接口没有使量子分支超过经典对照。

## 5. 新通道是否真正起作用

在训练后的 checkpoint 上将 `W_value` 临时清零，其余参数保持不变：

| 分支 | 训练态相对关闭 value 通道的 ADE 改善 | FDE 改善 |
|---|---:|---:|
| classical_value | 1.143% | 1.043% |
| quantum_value | 0.399% | 0.336% |

因此新增通道不是闲置参数，两个模型都使用了它；经典分支利用程度明显更高。

通道因子统计也支持这一点：

| 统计 | classical_value | quantum_value |
|---|---:|---:|
| 均值 | 0.760 | 0.844 |
| 标准差 | 0.279 | 0.260 |
| 落在 [0.8, 1.2] 外的比例 | 62.83% | 50.26% |
| `W_value` L2 范数 | 3.866 | 2.703 |

经典核心学到了更强、更广泛的通道重标定；量子核心的调制更接近中性值 1。这与其较小的收益一致。

## 6. 结论

本实验否定了“只要让量子输出进入 value，QGNN 就会超过 MLP”这一简单假设。当前瓶颈进一步收窄为：

1. 六比特电路的 12 维测量表示能够驱动 value 通道，但可供线性读出使用的任务相关变化仍弱于经典核心。
2. 现有乘性通道调制主要学成消息抑制，经典核心能利用得更充分；量子核心没有形成独有或更高效的表示。
3. 仅扩大下游读出职责不会自动产生量子优势，继续堆叠类似门控的收益预计很低。

下一项最有判别力的实验应改变量子表示本身，而非继续增加同类读出：在保持六比特的前提下，从头训练较小的编码角度范围，并同时检查测量有效秩、角度饱和比例和最终误差。若较小角度仍无改善，再进行量子比特数或观测量消融会更合理。
