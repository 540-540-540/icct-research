# 第一图：目标—目标交互图（已完成）

## 1. 模块定位

该模块解决的是：在已经获得各目标历史航迹及其身份的条件下，如何利用车辆之间的相对位置、相对速度、接近趋势和碰撞风险，对多个目标进行联合轨迹预测。

当前完整链路为：

```text
已知身份的多目标历史状态
        ↓
目标—目标交互图
        ↓
图节点上下文
        ↓
不确定性引导的运动 Token
        ↓
GPT-2/LoRA 时序预测
        ↓
多目标未来轨迹
```

该模块已经完成模型训练、传统模型对比、模块消融、多 SNR 评估和多目标轨迹可视化。但它使用的是已经整理好的目标航迹，尚未解决无身份量测条件下的数据关联问题。

## 2. 本归档包含的内容

- `documents/`：研究进度、模型流程、实验分析和最终结果清单；
- `code_snapshot/`：目标交互图、Graph+LLM、场景数据集和训练评估入口的代码快照；
- `results_snapshot/`：阶段结果、多 SNR 对比和消融结果的轻量文件；
- `figures/`：第一图阶段已经确定的论文图及其指标文件。

## 4. 与第二图的接口

第二图“量测—航迹关联图”应在时间流程上位于本模块之前。其输出包括：

1. 每条确认航迹的身份与当前状态后验；
2. 状态协方差；
3. 航迹置信度；
4. 关联概率及关联熵；
5. 目标有效掩码与生命周期状态。

这些输出将替代当前第一图所使用的 oracle 身份和直接状态观测，并作为目标交互图及不确定性运动 Token 的输入。
