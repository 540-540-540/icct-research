## 1. 当前研究问题与准确边界

### 1.1 当前已经解决的问题

给定同一交通场景中多个目标过去一段时间的带身份历史状态，预测所有目标未来一段时间的二维轨迹。模型不仅利用单个目标自身的运动历史，还显式建模目标之间的相互作用，并利用不确定性引导的运动 Token 和预训练 GPT-2 提升未来轨迹预测性能。

当前任务可形式化为：

\[
\mathcal{X}=\{\mathbf{x}_{i,t}\mid i=1,\ldots,M;\ t=1,\ldots,T_h\}
\longrightarrow
\hat{\mathcal{Y}}=\{\hat{\mathbf{p}}_{i,t}\mid i=1,\ldots,M;\ t=1,\ldots,T_f\},
\]

其中：

- \(M\leq 8\) 为场景内目标数量；
- \(T_h=20\) 为历史长度；
- \(T_f=20\) 为预测长度；
- 原始数据时间间隔为 \(\Delta t=0.1\text{ s}\)，因此历史 2 s、预测 2 s；
- 单个目标状态为 \(\mathbf{x}_{i,t}=[x,y,v_x,v_y]\)；
- 输出为每个目标未来 20 帧的二维位置 \([x,y]\)。

### 1.2 当前输入中的“身份已知”具体指什么

数据预处理使用原始 NGSIM 数据中的 `Vehicle_ID` 将不同时刻属于同一辆车的状态连接成连续轨迹。因此，模型输入已经被整理为：

```text
目标 A：A 在过去 20 帧的状态
目标 B：B 在过去 20 帧的状态
目标 C：C 在过去 20 帧的状态
……
```

`Vehicle_ID` 的数值本身没有作为神经网络输入特征，但它被用于：

1. 判断跨帧状态是否属于同一目标；
2. 保持目标在张量中的槽位一致；
3. 筛选历史与未来窗口内连续存在的目标；
4. 构造预测监督标签。

因此，目前的数据关联问题已经由数据集真值 ID 预先解决。

### 1.3 当前尚未解决的问题

当前尚未输入原始多 BS 回波或无身份量测集合，也没有处理：

- 漏检；
- 虚警；
- 新目标出现与旧目标离开；
- 一个量测应匹配哪条已有航迹；
- 目标交叉后的 ID Switch；
- 航迹创建、确认、维持和删除。

所以当前工作应准确表述为：

> 真值轨迹 ID 条件下的多目标交互轨迹预测。

不能暂时表述为：

> 从多 BS 回波到身份维护和未来预测的完整端到端多目标跟踪。

## 2. 数据来源与输入构造

### 2.1 原始数据

当前使用：

```text
Lankershim_Vehicle_Trajectories.csv
```

预处理主要使用以下字段：

| 字段 | 作用 |
|---|---|
| `Vehicle_ID` | 连接同一车辆的跨帧状态，仅用于数据构建和监督 |
| `Global_Time` | 保留多目标共同时间轴 |
| `Local_X` | 横向位置，原始单位英尺 |
| `Local_Y` | 纵向位置，原始单位英尺 |

位置按照 \(1\text{ ft}=0.3048\text{ m}\) 转换为米；速度由相邻连续帧位置差分获得，并且不会跨越数据缺口进行差分。

### 2.2 为什么没有直接复用第一研究点的单目标样本

第一研究点的数据处理以单车轨迹窗口为单位，会破坏同一 `Global_Time` 下不同车辆的同步关系。目标交互图需要知道哪些车辆在同一时刻共同出现，因此第二研究点直接从原始 CSV 重新构建场景。

### 2.3 场景构造流程

每个场景的具体构造步骤为：

1. 按 `Global_Time` 和 `Vehicle_ID` 排序；
2. 将全局时间映射为连续时间索引；
3. 为每辆车建立连续状态序列 \([x,y,v_x,v_y]\)；
4. 在候选起点提取长度为 40 帧的窗口，其中前 20 帧为历史、后 20 帧为预测真值；
5. 要求被选目标在 40 帧内连续存在；
6. 在历史最后一帧选择锚目标；
7. 搜索锚目标 45 m 半径内的同步目标；
8. 每个场景至少 2 个目标、最多保留 8 个目标；
9. 按“锚目标优先、其他目标按距离排序”填入固定目标槽位；
10. 不足 8 个目标的部分用 0 填充，并通过 `mask` 排除；
11. 以锚目标最后历史位置为原点、锚目标航向为局部坐标轴，对所有位置和速度进行平移旋转；
12. 将场景保存为压缩 NPZ 缓存。

### 2.4 数据张量形式

缓存文件：

```text
data/multitarget_lankershim_v1.npz
```

主要张量为：

| 张量 | 形状 | 含义 |
|---|---|---|
| `states` | `[N, 40, 8, 4]` | 40 帧、最多 8 个目标的 `[x,y,vx,vy]` |
| `history` | `[B, 20, 8, 4]` | 模型历史输入 |
| `future` | `[B, 20, 8, 4]` | 未来监督，其中评估主要使用位置 |
| `mask` | `[B, 8]` | 目标是否真实存在 |
| `target_ids` | `[B, 8]` | 数据审计用真值 ID，不作为网络特征 |
| `start_index` | `[B]` | 场景起始时间索引 |

### 2.5 数据集划分

数据沿原始时间轴进行划分，而不是把高度重叠的窗口随机拆分：

- 训练集：前 70%，6000 个场景；
- 验证集：中间 15%，1200 个场景；
- 测试集：最后 15%，1200 个场景。

其他配置：

- 窗口起点步长：3 帧；
- 每个候选时刻最多构造 2 个锚场景；
- 随机种子：2026。

这种时间段隔离降低了相邻重叠窗口同时进入训练集和测试集造成的数据泄漏风险。

### 2.6 观测噪声

为了模拟感知状态估计误差，在历史输入中加入高斯噪声：

\[
\tilde{\mathbf{p}}=\mathbf{p}+\boldsymbol{\epsilon}_p,
\quad \boldsymbol{\epsilon}_p\sim\mathcal{N}(0,0.35^2),
\]

\[
\tilde{\mathbf{v}}=\mathbf{v}+\boldsymbol{\epsilon}_v,
\quad \boldsymbol{\epsilon}_v\sim\mathcal{N}(0,0.20^2).
\]

位置噪声单位为米，速度噪声单位为米每秒。测试时使用固定随机种子，使所有模型面对完全相同的噪声 realization。

## 3. 整体模型流程

当前模型的完整信息流为：

```text
同步多目标历史状态 [B,20,8,4]
            │
            ├── 每目标相对位置、速度、加速度特征
            │
            ▼
       共享 GRU 历史编码器
            │
            ▼
     每个目标的 128 维节点特征
            │
            ├── 构造目标—目标交互边
            │   相对位置 / 相对速度 / 距离 / 接近速度 / TTC
            ▼
     两层多头图注意力网络
            │
            ├──────────────► GNN 基础未来轨迹
            │
            ├── 图节点特征生成不确定性温度
            │
            ├── 历史局部位移软量化为运动 Token 分布
            │
            ▼
      图上下文 + 运动 Token Embedding
            │
            ▼
       本地 GPT-2（4 层）+ LoRA
            │
            ├── 未来运动 Token 分类
            │
            └── 坐标残差修正
                         │
                         ▼
                最终多目标未来轨迹
```

## 4. 模型一：匀速基线

匀速模型使用最后历史状态进行外推：

\[
\hat{\mathbf{p}}_{i,t}=\tilde{\mathbf{p}}_{i,T_h}
+t\Delta t\tilde{\mathbf{v}}_{i,T_h}.
\]

它没有可训练参数，用于判断数据上的基础运动可预测性。

---

## 5. 模型二：独立 GRU 基线

### 5.1 输入特征

每个目标独立构造 6 维历史特征：

\[
\mathbf{f}_{i,t}=
[\Delta x_{i,t},\Delta y_{i,t},v_{x,i,t},v_{y,i,t},a_{x,i,t},a_{y,i,t}],
\]

其中位置相对于该目标最后历史位置计算。实现中使用：

- 位置归一化尺度：20 m；
- 速度归一化尺度：15 m/s；
- 加速度由相邻速度差除以 \(\Delta t\) 得到。

### 5.2 历史编码

所有目标共享同一个 GRU：

- 输入维度：6；
- 隐藏维度：128；
- 每个目标独立编码；
- 不在目标之间传递消息。

GRU 最终隐状态与最后位置、最后速度拼接，得到每目标节点表示。

### 5.3 轨迹解码

解码器以匀速外推为物理先验：

\[
\hat{\mathbf{d}}^{CV}_{i,t}=t\Delta t\tilde{\mathbf{v}}_{i,T_h}.
\]

网络输入包括：

- 128 维目标表示；
- 24 维未来时刻嵌入；
- 当前时刻的匀速位移。

MLP 输出残差位移，最终位移为：

\[
\hat{\mathbf{d}}_{i,t}
=\hat{\mathbf{d}}^{CV}_{i,t}+\Delta\hat{\mathbf{d}}_{i,t}.
\]

独立 GRU 可训练参数量为 98,210。

## 6. 模型三：目标交互图神经网络

### 6.1 图节点

每个有效目标对应一个图节点，初始节点表示来自共享 GRU 历史编码器。因此，GNN 和独立 GRU 使用相同的单目标运动骨干，主要差异是是否进行目标间消息传递。

### 6.2 图连接规则

若目标 \(i\) 与 \(j\) 在历史最后时刻的距离不超过 45 m，则建立边；每个有效节点同时保留自环。

### 6.3 七维边特征

有向边 \(i\leftarrow j\) 的特征包括：

\[
\mathbf{e}_{ij}=
[\Delta x_{ij},\Delta y_{ij},
\Delta v_{x,ij},\Delta v_{y,ij},
d_{ij},c_{ij},\tau_{ij}],
\]

其中：

- \(\Delta\mathbf{p}_{ij}=\mathbf{p}_j-\mathbf{p}_i\)：相对位置；
- \(\Delta\mathbf{v}_{ij}=\mathbf{v}_j-\mathbf{v}_i\)：相对速度；
- \(d_{ij}=\|\Delta\mathbf{p}_{ij}\|_2\)：目标距离；
- \(c_{ij}\)：沿相对位置方向的接近速度；
- \(\tau_{ij}\)：截断后的近似碰撞时间 TTC。

### 6.4 图注意力层

当前使用：

- 图层数：2；
- 每层注意力头数：4；
- 节点维度：128；
- 边特征同时影响注意力偏置和传递的消息值；
- 使用残差连接、LayerNorm、前馈网络和 Dropout。

注意力可概括为：

\[
s_{ij}^{(h)}=
\frac{(W_Q^{(h)}\mathbf{h}_i)^T(W_K^{(h)}\mathbf{h}_j)}{\sqrt{d_h}}
+\phi_h(\mathbf{e}_{ij}),
\]

\[
\alpha_{ij}^{(h)}=\operatorname{softmax}_{j\in\mathcal{N}(i)}s_{ij}^{(h)},
\]

\[
\mathbf{m}_{i}^{(h)}=
\sum_{j\in\mathcal{N}(i)}\alpha_{ij}^{(h)}
\left(W_V^{(h)}\mathbf{h}_j+\psi_h(\mathbf{e}_{ij})\right).
\]

### 6.5 稳定训练设计

GNN 从训练完成的独立 GRU 权重热启动，新增图层的残差门初始化为 0。刚接入图网络时，模型严格退化为独立预测器，然后只学习有验证收益的交互修正。

目标交互 GNN 可训练参数量为 400,558。

## 7. 模型四：目标交互 GNN + 不确定性运动 Token + GPT-2/LoRA

### 7.1 为什么在 GNN 通过后才接入 LLM

实验采用阶段闸门：首先验证目标交互图本身是否有效。如果 GNN 不能优于独立 GRU，则不继续增加 LLM，以免用更大模型掩盖图结构无效的问题。正式实验中第一阶段已通过。

### 7.2 冻结已验证的 GNN

第二阶段加载第一阶段最佳 GNN，并冻结其参数。GNN 输出：

- 基础未来轨迹；
- 128 维目标节点特征；
- 图注意力和邻接关系。

### 7.3 Agent-centric 运动 Token

对每个目标，将相邻历史位置变化旋转到目标自身航向坐标系，得到：

- 前向位移 \(\Delta p_f\)；
- 横向位移 \(\Delta p_l\)。

当前 Token 网格为：

- 前向 21 个区间，范围约为 \([-0.5,1.5]\) m/帧；
- 横向 21 个区间，范围约为 \([-1.0,1.0]\) m/帧；
- 总词表大小：\(21\times21=441\)。

每个 Token 对应一个前向—横向局部运动原语。

### 7.4 不确定性引导的软 Token 化

模型不直接把每个历史位移硬分配给唯一 Token，而是预测温度参数：

\[
T_i=0.04+0.36\cdot\sigma(g([\mathbf{h}_i,u_i^{acc},u_i^{speed}])),
\]

其中：

- \(\mathbf{h}_i\) 为 GNN 节点特征；
- \(u_i^{acc}\) 为历史平均加速度幅值；
- \(u_i^{speed}\) 为历史速度变化程度；
- 温度范围为 0.04--0.40 m。

历史运动对 Token \(k\) 的概率为：

\[
P(z_{i,t}=k)\propto
\exp\left(
-\frac{(\Delta p_f-c_{f,k})^2+(\Delta p_l-c_{l,k})^2}{T_i^2}
\right).
\]

温度低时分布更接近硬 Token；温度高时概率分散到多个相近运动原语，表示更大的运动不确定性。

### 7.5 图上下文注入

GNN 节点表示经过投影得到 768 维图上下文 Token。该图上下文：

1. 作为 GPT-2 序列的第一个 Token；
2. 加到每个历史运动 Token Embedding 上。

因此 GPT-2 不只看到单目标运动序列，也获得该目标与邻居交互后的图语义。

### 7.6 GPT-2 与 LoRA

当前配置：

- 使用服务器本地 `gpt2/` 权重，不在线下载；
- GPT-2 隐藏维度：768；
- 使用前 4 层 Transformer；
- GPT-2 主体冻结；
- LoRA rank：8；
- LoRA 注入 `c_attn` 和 `c_proj`；
- 模型总参数量：70,643,348；
- 可训练参数量：2,505,958。

### 7.7 两个输出头

GPT-2 后连接两个任务头：

1. **未来运动 Token 头**：对未来 20 个时间步分别输出 441 类 Token logits，用作辅助监督；
2. **坐标残差头**：结合 GPT-2 隐状态和 GNN 节点特征，输出未来 20 帧二维坐标修正，最大修正尺度为 3 m。

最终预测为：

\[
\hat{\mathbf{Y}}^{final}
=\hat{\mathbf{Y}}^{GNN}+\Delta\hat{\mathbf{Y}}^{LLM}.
\]

坐标残差头最后一层采用全零初始化，所以第二阶段训练开始时：

\[
\hat{\mathbf{Y}}^{final}=\hat{\mathbf{Y}}^{GNN}.
\]

这保证 Graph+LLM 初始性能不会因随机残差破坏已经通过验证的 GNN。

## 8. 训练目标

### 8.1 坐标预测损失

坐标误差使用 Smooth L1。未来时间权重从 0.5 线性增加到 1.5，使模型更关注较远预测时刻：

\[
\mathcal{L}_{traj}=
\frac{\sum_{i,t}m_iw_t\operatorname{SmoothL1}
(\hat{\mathbf{p}}_{i,t},\mathbf{p}_{i,t})}
{\sum_{i,t}m_iw_t}.
\]

对于 15 m 内存在邻居的交互目标，GNN 和 Graph+LLM 训练时权重额外乘以 1.35。

最终时刻另加：

\[
\mathcal{L}_{coord}=\mathcal{L}_{traj}+0.15\mathcal{L}_{final}.
\]

### 8.2 未来 Token 辅助损失

Graph+LLM 使用未来运动 Token 交叉熵：

\[
\mathcal{L}_{token}=\operatorname{CE}(\hat{z}_{i,t},z_{i,t}).
\]

第二阶段总损失为：

\[
\mathcal{L}_{LLM}=\mathcal{L}_{coord}+0.035\mathcal{L}_{token}.
\]

### 8.3 优化配置

| 阶段 | 主要配置 |
|---|---|
| 独立 GRU | AdamW，初始学习率 `1e-3`，最多 35 轮 |
| 目标交互 GNN | 从 GRU 热启动，学习率 `4e-4`，最多 30 轮 |
| Graph+LLM | 头部学习率 `3e-4`，LoRA 学习率为其 0.25 倍，最多 16 轮 |

所有阶段使用：

- 验证集选择最佳检查点；
- CosineAnnealing 学习率调度；
- 梯度裁剪；
- CUDA 混合精度；
- 远程 RTX 4090；
- 固定测试噪声以保证公平比较。

## 9. 分阶段实验流程

### 阶段 0：数据与流程连通性检查

1. 构建小规模多目标缓存；
2. 检查时间同步、目标掩码和坐标变换；
3. 对独立 GRU 和 GNN 各训练 1 轮；
4. 确认训练、保存、加载和评估链路可运行。

小规模结果仅作为软件检查，不作为论文结论。

### 阶段 1：独立 GRU 与目标交互 GNN

1. 构建 6000/1200/1200 个正式场景；
2. 训练独立 GRU；
3. 将独立 GRU 权重加载到 GNN；
4. 训练图交互层和预测器；
5. 在相同测试集、相同噪声下比较；
6. 闸门规则：GNN 的测试 ADE 和 FDE 必须同时低于独立 GRU。

结果：第一阶段闸门通过。

### 阶段 2：Graph+LLM

1. 加载第一阶段最佳 GNN；
2. 冻结 GNN；
3. 构造不确定性引导的历史软运动 Token；
4. 注入图上下文；
5. 使用本地 GPT-2 和 LoRA 训练；
6. 同时优化坐标预测和未来 Token 分类；
7. 闸门规则：Graph+LLM 测试 ADE 和 FDE 必须同时低于 GNN。

结果：第二阶段闸门通过。

### 阶段 3：传统时序模型横向对比

为避免只用“逐步加模块”的结果支撑结论，按照第一研究点中的基线类别，在同一多目标数据接口上补充：

1. LSTM：两层、隐藏维度 256，逐目标独立预测；
2. TCN：三层因果膨胀卷积，通道数 64/128/256，逐目标独立预测；
3. Transformer：4 层、8 头、隐藏维度 256，逐目标独立预测；
4. 三者与本文方法使用完全相同的场景缓存、时间划分、观测噪声和测试噪声种子；
5. 三者均使用相同的 6 维运动输入、匀速锚点和多步残差解码器，只改变时序编码器；
6. 所有对比模型均按验证集综合指标选取最佳检查点，再在测试集评估。

结果：LSTM、TCN、Transformer 均正常收敛，本文 Graph+LLM 在测试 ADE 和 FDE 上均为最优，横向对比闸门通过。

需要强调：阶段 1--2 属于“阶段基线/模块递进验证”，不是完整消融；阶段 3 才是与不同模型族进行的横向对比。严格消融仍需单独移除不确定性温度、软 Token、图上下文、LoRA、Token 辅助损失等组件。

## 10. 输出内容与评估指标

### 10.1 模型直接输出

Graph+LLM 返回：

| 输出 | 形状 | 含义 |
|---|---|---|
| `future_position` | `[B,20,8,2]` | 最终未来坐标 |
| `displacement` | `[B,20,8,2]` | 相对最后历史位置的未来位移 |
| `token_logits` | `[B,20,8,441]` | 未来运动 Token 分类 logits |
| `token_temperature` | `[B,8]` | 每目标不确定性温度 |
| `graph_future_position` | `[B,20,8,2]` | LLM 修正前的 GNN 轨迹 |
| `attention` | `[B,8,8]` | 最后一层目标交互注意力 |
| `adjacency` | `[B,8,8]` | 目标交互邻接关系 |

这些中间量后续可用于论文可视化，例如展示高交互场景的注意力、目标不确定性温度和 LLM 修正前后轨迹。

### 10.2 ADE

平均位移误差：

\[
\operatorname{ADE}=
\frac{1}{\sum_i m_iT_f}
\sum_i\sum_{t=1}^{T_f}m_i
\|\hat{\mathbf{p}}_{i,t}-\mathbf{p}_{i,t}\|_2.
\]

### 10.3 FDE

最终位移误差：

\[
\operatorname{FDE}=
\frac{1}{\sum_i m_i}
\sum_i m_i
\|\hat{\mathbf{p}}_{i,T_f}-\mathbf{p}_{i,T_f}\|_2.
\]

### 10.4 交互目标指标

若一个目标在最后历史时刻的 15 m 内存在其他有效目标，则归入交互子集，单独计算 Interaction ADE 和 Interaction FDE。

### 10.5 碰撞指标

当任意目标对预测距离小于 2 m 时，记为预测碰撞。当前输出：

- `collision_rate`：预测轨迹中的场景—时间碰撞率；
- `ground_truth_collision_rate`：真值轨迹中的对应碰撞率；
- `excess_collision_rate`：预测发生但真值未发生的额外碰撞率。

## 11. 正式实验结果

### 11.1 验证集结果

| 模型 | ADE/m ↓ | FDE/m ↓ | 交互 ADE/m ↓ | 交互 FDE/m ↓ | 额外碰撞率 ↓ |
|---|---:|---:|---:|---:|---:|
| 独立 GRU | 0.6546 | 1.3604 | 0.6394 | 1.3285 | 0.7625% |
| LSTM | 0.5965 | 1.2366 | 0.5848 | 1.2128 | 0.5708% |
| TCN | 0.6142 | 1.2609 | 0.6006 | 1.2312 | 0.4042% |
| Transformer | 0.6344 | 1.2941 | 0.6215 | 1.2668 | 0.7292% |
| 目标交互 GNN | 0.5769 | 1.1638 | 0.5631 | 1.1342 | 0.3708% |
| Graph+LLM | **0.5490** | **1.1051** | **0.5360** | **1.0770** | 0.3542% |

### 11.2 测试集结果

| 模型 | ADE/m ↓ | FDE/m ↓ | 交互 ADE/m ↓ | 交互 FDE/m ↓ | 额外碰撞率 ↓ |
|---|---:|---:|---:|---:|---:|
| 匀速模型 | 1.0563 | 2.0387 | 1.0246 | 1.9657 | 3.9042% |
| 独立 GRU | 0.7001 | 1.4685 | 0.6731 | 1.4103 | 0.5875% |
| LSTM | 0.6266 | 1.2980 | 0.6059 | 1.2558 | 0.7917% |
| TCN | 0.6472 | 1.3373 | 0.6253 | 1.2924 | 0.6500% |
| Transformer | 0.6836 | 1.4018 | 0.6583 | 1.3492 | 0.7208% |
| 目标交互 GNN | 0.6202 | 1.2529 | 0.5956 | 1.2012 | **0.2167%** |
| Graph+LLM | **0.5925** | **1.1956** | **0.5673** | **1.1439** | 0.2792% |

### 11.3 相对性能提升

GNN 相对独立 GRU：

- ADE 降低 11.42%；
- FDE 降低 14.68%；
- 交互目标 ADE 降低 11.52%；
- 额外碰撞率从 0.5875% 降至 0.2167%。

Graph+LLM 相对 GNN：

- ADE 进一步降低 4.47%；
- FDE 进一步降低 4.57%；
- 交互目标 ADE 进一步降低 4.74%；
- 额外碰撞率由 0.2167% 上升到 0.2792%，说明精度提高但安全约束仍需增强。

Graph+LLM 相对独立 GRU：

- ADE 约降低 15.38%；
- FDE 约降低 18.58%；
- 交互目标 ADE 约降低 15.72%；
- 额外碰撞率约降低 52.48%。

Graph+LLM 相对传统横向基线：

| 对比模型 | ADE 降低 | FDE 降低 | 交互 ADE 降低 |
|---|---:|---:|---:|
| LSTM | 5.44% | 7.88% | 6.37% |
| TCN | 8.46% | 10.59% | 9.28% |
| Transformer | 13.34% | 14.71% | 13.83% |

因此，当前结果可以表述为：在本实验设置和已测试模型范围内，Graph+LLM 获得最优 ADE/FDE；不能表述为对所有多目标预测方法“绝对最优”。

### 11.4 当前能够支持的实验结论

目前结果支持以下结论：

1. 在相同单目标运动编码器和相同测试条件下，目标交互图显著优于逐目标独立预测，说明显式目标交互建模有效；
2. 对交互目标子集的改善与总体改善一致，说明收益不是只来自稀疏场景；
3. 图上下文、不确定性软运动 Token 和 GPT-2/LoRA 在已验证 GNN 上进一步降低 ADE/FDE；
4. 本文方法同时优于 LSTM、TCN 和 Transformer，说明性能收益不只来自选择某一种常规时序编码器；
5. 最终模型仍需加入显式安全约束，因为其额外碰撞率略高于纯 GNN；
6. 这些结论目前基于一个固定随机种子，应在论文最终版本中补充多随机种子统计和显著性检验；
7. 当前 LSTM/TCN/Transformer 是与第一研究点一致的传统模型族，但若面向较强的多智能体轨迹预测论文，还应增加至少 2--3 个公开多目标交互模型作为外部基线。

## 15. 论文写作可使用的结构

### 15.1 方法章节建议

1. **System Model and Problem Formulation**  
   定义多目标历史状态、预测目标和后续多 BS 量测模型。

2. **Synchronized Multi-target Scene Construction**  
   说明共同时间轴、锚目标坐标系、目标筛选和时间隔离划分。

3. **Target Interaction Graph Encoder**  
   说明节点、七维边特征、图注意力和匀速残差解码。

4. **Uncertainty-guided Motion Tokenization**  
   说明 agent-centric 局部运动原语、温度预测和软 Token 分布。

5. **Graph-conditioned LLM Predictor**  
   说明图 Token 注入、GPT-2、LoRA、未来 Token 头和坐标残差头。

6. **Training Objectives**  
   说明时间加权轨迹损失、最终时刻损失和 Token 交叉熵。

7. **Measurement-to-track Association Graph**（下一阶段）  
   说明无身份量测、二部图关联、航迹管理和关联不确定性。

### 15.2 当前可提炼的创新点草稿

以下表述可作为后续论文创新点的初稿，但正式写作前应在完整消融和第二张图完成后收紧措辞：

1. 提出一种面向多目标场景的交互图编码方法，利用相对位置、相对速度、接近速度和 TTC 描述目标间动态影响；
2. 提出图条件的不确定性运动 Token 化方法，根据目标运动变化和图语义自适应控制 Token 分布软硬程度；
3. 将图交互表征作为上下文 Token 注入预训练语言模型，并通过未来运动 Token 辅助监督和坐标残差预测实现多目标联合轨迹预测；
4. 采用分阶段性能闸门，分别验证交互图和 LLM 模块相对其直接基线的增益。

### 15.3 当前不能直接写入论文的强结论

在量测关联图完成前，不宜声称：

- 已实现端到端多 BS ISAC 多目标跟踪；
- 模型能从原始回波自动识别目标身份；
- 已解决漏检、虚警和 ID Switch；
- 当前 ADE/FDE 结果能够证明数据关联性能；
- 已完成完整“双图”系统。
